System design

One substrate, multiple neural modalities.

The central engineering decision is to separate modality-specific loading from a shared neural-token backbone, then test predictive and intervention-aware heads instead of treating parameter count as evidence.

01 · INGEST

Public neural data

IBL, DANDI, Allen, OmniMouse, OSF, GIN, OpenNeuro, PhysioNet, Figshare and controlled synthetic data.

02 · TOKENIZE

BrainToken-style adapters

Spikes, dF/F, events and EEG are normalized into explicit token-ready windows with provenance and split rules.

03 · FOUNDATION

Shared neural backbone

MtM/NEDS-style objectives test neuron, causal-time, intra-region, inter-region and multimodal reconstruction.

04 · WORLD

Predict the future

Causal-future masking hides future brain and behavior so the model must infer state transitions rather than classify static labels.

05 · APPLY

Behavior & intervention

Decode state, predict behavior, quantify future dynamics, and test whether explicit interventions improve forecasting.

Embodied 5-event social world

27 animals · Observe / Unrewarded / Active / Passive / Other
WORLD MODEL
+0.0135 bits/event
Neural social world over full-history linear on 5-event NLL

The neural social world model improves the full-history linear comparator in 22/27 animals (one-sided p = 0.00015). The larger gain is in future social-sampling action: +0.0353 bits/event. Outcome classification itself is not improved.

Learning also rewrites the event graph: Observe→Active rises by +0.047, while Unrewarded→Observe rises by +0.190 in learners.

A stricter leave-one-experimental-cohort-out test gives a median +0.0849 bits/trial slow-state lift over exogenous+history, positive in 7/7 cohorts. This includes Chemo, Jaws, OXT, DMS and VTA-JAWS cohorts rather than only leave-one-animal-out.

A training-only PCA compression shows a 2-D shared slow latent preserves 93.0% of the full six-feature median transfer gain and remains positive in 7/7 held-out cohorts. This supports a compact shared slow-state bottleneck rather than separate transmitter-specific state copies.

More importantly, the state no longer needs to be hand-engineered: a 4-D GRU with only 161 parameters, trained only from current action/outcome and current exogenous cues, reaches 0.1768 bits/trial median on leave-one-cohort-out transfer. It beats a matched current-state linear model, an 8-unit feedforward MLP, and a current+previous-trial linear control in 7/7 cohorts. Against the strongest current+previous control the paired median gain is +0.0579 bits/trial (one-sided sign and Wilcoxon p = 0.0078).

The history requirement is graded rather than one-step: keeping the same trained GRU but forcibly resetting its recurrent state every 1 / 2 / 4 / 8 / 16 / 32 trials yields median predictive information of 0.0688 / 0.0790 / 0.0934 / 0.1137 / 0.1359 / 0.1515 bits/trial, versus 0.1649 with full-session memory. Thus 32 trials retain 91.9% of full-session median predictive information, showing that the useful state integrates tens of trials rather than only the immediately preceding event.

Real VTA dopamine intervention anchors the slow state

user JAWS authority · corrected OFF / ON labels · 10 animals
CAUSAL ANCHOR
Δ Active belief = −0.0401
ON − OFF · 10/10 animals decrease · p = 0.00195

Acute VTA dopamine inhibition selectively weakens the observation-conditioned Active reward/belief coordinate and active observation value. Passive belief changes by only +0.0109 (p = 0.275), while gross observation fraction changes by +0.0432 (p = 0.922), arguing against a simple suppression of observing itself.

The result survives a count/order-preserving null (Active-belief empirical p = 0.0494) and a continuous no-reset replay (Active-belief update p = 0.00195). Across animals, the JAWS-induced Active-belief shift covaries with the change in rewarded-observation conversion (ρ = 0.673, p = 0.033), but not with total observation amount.

This makes the slow state biologically interpretable without claiming that GRU units are literal dopamine variables: the learned recurrent state tracks a reward-credit quantity that is selectively perturbed by causal VTA manipulation.

Learned-latent audit: the initial raw GRU hidden-state probe shifts in 9/10 animals (p = 0.00488), but that effect is composition-sensitive. A stricter pre-registered follow-up now closes the question: after making the state pre-event and scrubbing current action/outcome nuisance, the composition-adjusted shift is only 5/10 animals in the expected direction (p = 0.50); after also removing the current plus two immediately preceding event compositions it is 6/10 (p = 0.348). All three robust gates fail.

The conclusion is therefore narrower and cleaner: the GRU is a useful predictive slow state, but it is not independently validated as a composition-robust causal VTA latent. The exact-replay belief-coordinate result above remains the causal anchor. The next model stage treats JAWS ON/OFF explicitly as an intervention/action token and asks whether intervention-aware dynamics improve held-out-animal future prediction and counterfactual direction.

On Macaque DANDI001435, the frozen SOE recurrent core improves target NLL in 10/10 sessions at full target data (mean gain +0.01284, one-sided p = 0.00098) and in 8/10 sessions at 50% target data. The evaluation freezes the source recurrent core and trains only the target adapter/head.

No monotonic scale law

The initial sampled-window plateau survives the stricter test. At 423 sessions, continuous held-out 100-ms co-bps is tiny 0.148, base 0.165, and large 0.145; the formal gates for both data scaling and globally monotonic parameter scaling are FALSE.

Using all selected units improves absolute 100-ms performance to 0.178 / 0.177 / 0.167. Extended compute gives 0.162 / 0.153 / 0.166. Real intervention-conditioned forecasting

McBride claustrum optogenetics · cortical Neuropixels · held-out trials
PERTURBATION AWARE
106 / 120 trials
true action beats no-action likelihood · sign p = 5.78×10−19

True intervention identity improves future cortical population likelihood over no-action and predeclared wrong-action controls. It beats cyclic-wrong on 88/120 trials (sign p = 1.59×10−7), while generative 4-way action identification reaches 58.3% vs 25% chance with permutation p < 10−4.

The true-action gain grows from +0.00220 co-bps at 40 ms to +0.00739 at 500 ms. A deliberately adversarial post-hoc best-wrong comparator is only borderline/non-robust (sign p = 0.041; Wilcoxon p = 0.137), and absolute co-bps remains below zero. This is one mouse/probe, not an across-animal causal-generalization claim.

Model audit

Large linked models are not the same as large shared backbones.

Full 423-session linking exposes a critical scaling problem: session-specific embeddings and stitchers dominate total parameters. That motivates a token-native shared backbone rather than simply inflating session-specific weights.

Scientific boundary

Prediction is not intervention. IBL and other observational recordings can establish generalization and future-state prediction, but they cannot by themselves establish causal control. The intervention branch therefore uses controlled synthetic ground truth now and is ingesting real perturbation datasets separately.

Size is not evidence. The full-data NEDS world-model configuration reaches 1.51B linked parameters, but only ~75.9M are shared backbone-like parameters; most of the linked count is session/stitcher-specific. Scaling decisions are gated by held-out predictive performance.
