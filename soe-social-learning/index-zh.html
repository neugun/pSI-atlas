一个社会学习闭环：小鼠如何决定何时观察同伴、如何把社会信息转化为自身行动，并根据结果继续学习

这项工作把社会学习拆成一条可检验的闭环：小鼠先判断同伴是否值得观察，把短期和跨天经验整合成采样策略；观察到的具体内容会改变自身进食；结果出现后，腹侧被盖区多巴胺参与更新未来的社会信息采样。社会学习模型（SLM）给出可解释机制，社会世界模型（SWM）提供独立的数据驱动检验和扩展。

主要术语｜社会观察进食（SOE）；社会学习模型（SLM）；社会世界模型（SWM）；腹侧被盖区（VTA）；多巴胺（DA）；动作预测误差（APE）；奖励预测误差（RPE）；强化学习（RL）；社会反应指数（SRI）。JAWS 指本研究使用的红移光遗传抑制工具。预测指标中，AUC 表示曲线下面积，Brier 表示概率校准误差，NLL 表示负对数似然，RMSE 表示均方根误差，SEM 表示均值标准误。

核心计算模型

一个紧凑的社会学习模型解释小鼠何时主动获取社会信息，以及经验如何改变采样策略

SLM 把当前状态、近期社会经历、采样策略和结果特异的社会归因压缩成一组可由神经记录和因果实验继续检验的变量。

这项工作推进了什么 · 这项工作的核心贡献是把行为描述推进为机制变量：同一组计算既解释选择，又能够继续检验 VTA、JAWS 和生成式智能体是否实现这些步骤。
问题什么样的紧凑计算能解释这些选择？
怎么做从简单基线和经典强化学习模型逐步比较到默认 SLM；灵活模型只用于评估预测容量上限。
意味着什么SLM 保留接近上限的预测能力，同时留下可直接进行神经和因果检验的变量。
先分清三个层次。 函数形式看线性/逻辑回归还是非线性/循环网络；学习架构看模型内部维护什么状态，例如经典价值、选择惯性、结构化 SLM 状态或数据驱动潜在状态；计算读出看某个时间点读取采样策略、APE、RPE 或社会结果归因。三者回答的问题不同，不能混成同一个模型列表。
0 · 直接读出

基础发生率 / 时间进程 / 当前状态线性或非线性读出

原理：直接由可观测当前状态预测选择，不维护学习状态。

关键参数：截距、特征权重、训练数据内选择的正则化；非线性版本额外允许特征交互。

用途：建立没有学习规则时的预测基线。

1 · 经典学习规则

RW / WSLS / Q 学习 / 非对称 Q / 遗忘 Q / 选择惯性

原理：维护少量价值或选择惯性状态，并在选择或结果之后更新。

关键参数：学习率 α；需要时加入折扣/价值项 γ；非对称 Q 使用正负结果各自的学习率；遗忘 Q 加入遗忘率；选择惯性包含衰减和权重。

用途：提供奖赏学习和重复选择倾向的可解释替代模型；Q 系列在结果后产生 RPE。

2 · 机制假说

SLM 组成模块 → SLM 核心 → 默认 SLM

原理：当前状态和多时间尺度记忆共同决定观察策略；采样动作后产生 APE；结果出现后更新来源/结果特异的社会归因和价值。

关键参数：多时间尺度状态及衰减、策略读出权重、社会归因和价值学习项；默认行为 SLM 再加入通用选择惯性分支。

用途：作为主要机制模型；策略、APE、社会归因和价值在 VTA 与 JAWS 检验之前已经定义。

3 · 灵活非线性对照

历史多层感知机（MLP） / 完整历史 MLP / 小型循环网络（TinyRNN） / 线性动态网络（LDN）

原理：不预设 SLM 语义，自由学习非线性历史交互。

关键参数：隐藏层或循环网络权重、隐藏维度、正则化和训练超参数，全部只在训练数据内选择。

用途：作为容量上限和压力测试，检验通用记忆与非线性是否足以解释同一行为。

4 · 动力学模型

社会世界模型（SWM）

原理：不提供 SLM 方程，直接学习循环潜在状态来预测未来行为和社会动力学。

关键参数：编码器、循环潜在动力学以及未来状态/行为读出，端到端训练。

用途：检验与 SLM 对齐的坐标能否自行出现，并寻找 SLM 没有显式包含的前瞻性社会效益状态。

行为比较约定。 主要紧凑模型比较固定同一批 27 只留出动物、同一预测目标和逐动物留出评估；Brier 作为主要概率校准指标，AUC 和对数损失作为辅助。经典强化学习模型使用较窄的状态输入；检验“相同当前输入下 SLM 结构是否仍有价值”时，强对照复用同一当前状态骨架。多层感知机和循环网络只作为容量上限，不直接获得机制解释。
为什么页面上会出现不同的模型集合｜它们分别回答不同问题，不能合并成一张统一排行榜。行为模型库比较“谁更能预测观察”；输入匹配的机制判别固定当前状态骨架，专门问加入 SLM 结构后是否还有增量；VTA 模型检验不再重新训练行为模型，而是冻结行为阶段得到的策略、APE、RPE 和社会归因，再问这些计算量是否在预设神经时间窗中出现。因此只有在预测目标、事件集合和输入约定一致时才比较 Brier/AUC；跨层级不能直接把一个数字当成总排行榜。
后文统一术语。 采样策略是结果出现前选择观察的概率或规则。动作预测误差（APE） = 实际采样动作 − 动作前采样概率，在采样动作发生后、当前社会结果可用前计算。奖励预测误差（RPE）是结果后的奖赏/价值预测误差；Q 学习中 δ = r + γV′ − V。社会结果归因是结果出现后、带有信息来源和结果类别标签的更新。这些量属于不同时间点的计算读出。
