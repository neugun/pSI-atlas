一个社会学习闭环：小鼠如何决定何时观察同伴、如何把社会信息转化为自身行动，并根据结果继续学习

这项工作把社会学习拆成一条可检验的闭环：小鼠先判断同伴是否值得观察，把短期和跨天经验整合成采样策略；观察到的具体内容会改变自身进食；结果出现后，腹侧被盖区多巴胺参与更新未来的社会信息采样。社会学习模型（SLM）给出可解释机制，社会世界模型（SWM）提供独立的数据驱动检验和扩展。

主要术语｜社会观察进食（SOE）；社会学习模型（SLM）；社会世界模型（SWM）；腹侧被盖区（VTA）；多巴胺（DA）；动作预测误差（APE）；奖励预测误差（RPE）；强化学习（RL）；社会反应指数（SRI）。JAWS 指本研究使用的红移光遗传抑制工具。预测指标中，AUC 表示曲线下面积，Brier 表示概率校准误差，NLL 表示负对数似然，RMSE 表示均方根误差，SEM 表示均值标准误。
紧凑机制模型达到接近灵活模型的预测能力
机制与预测兼顾

默认 SLM 在留出动物上优于“当前状态+选择惯性”对照（20/27），也优于小型循环网络（23/27）；同时保留可直接对应神经和因果实验的内部变量。

独立世界模型重新找到并扩展同一套计算
独立验证并扩展

不预设 SLM 方程的 SWM 自主学到与 SLM 对齐的决策子空间，并额外学到“现在观察是否会提高之后成功进食概率”的前瞻性社会效益。

多巴胺跟随社会学习的真实计算顺序
决定 → 采样 → 学习

一次观察过程中，VTA 多巴胺依次反映结果前的采样策略、采样动作预测误差（APE），以及结果后的奖赏和社会结果归因更新。

VTA 活动参与结果后的社会教学
因果教学信号

JAWS 光抑制在全部 10 只动物中降低结果后的主动社会归因更新，并在 9/10 动物中降低累积社会归因，同时总体观察行为仍然保留。

看到同伴进食会改变学习者自己的进食
社会内容转为自身行动

学习者看到示范鼠进食后，自身短时进食概率上升；控制当前自身状态和社会位置关系后，该效应仍然存在。

核心计算能够接受跨任务和跨物种检验
外部证据分层

人类和大鼠数据为多时间尺度状态提供最强独立外部支持，其他跨物种结果按证据等级分别作为组成证据或架构支持。

核心贡献 · 这项工作把社会学习从一个现象推进成可检验的闭环机制：主动信息采样、社会内容到自身行动的转化，以及结果依赖的教学过程被连成同一条因果计算链。
社会状态 → 主动选择观察 → 采到的社会内容 → 自身进食反馈：社会结果 → 结果后的来源特异归因与价值更新 → 未来观察策略

页面按照生物学问题顺序展开：行为获得 → 信息价值 → 多时间尺度记忆 → 社会学习模型 → 数据驱动世界模型 → 社会内容到自身行动的转化 → 神经实现 → 因果拆解 → 机制综合 → 后续泛化 → 跨任务证据。

适应性信息觅食

同伴状态的价值会随观察者自身状态和学习阶段改变，说明动物会主动选择何时利用社会信息。

这项工作推进了什么 · 这把社会观察推进为主动的信息获取过程：动物会根据自身状态判断何时值得参考同伴。
问题什么时候社会信息最有用？
怎么做比较“只使用观察者自身状态”的基线与“加入完整社会状态”的模型，再检验自身状态是否门控这部分增量。

是否需要社会信息取决于自身状态
离食口更远时更依赖同伴

离自己的食口更远时，社会信息对下一步选择的增量价值更高。

为什么下一步必须看记忆｜状态门控解释当前时刻何时值得采样社会信息；真正的学习还要求一次观察的结果能够影响之后的选择。因此下一节直接测量这种内部状态能保留多久，从下一次决策、约五分钟一直到跨天。
多时间尺度学习

社会经验同时分布在秒、分钟和跨天多个时间尺度

一次结果会立即重设下一步是否还需要继续获取社会信息；最近多次社会经验会在数分钟内累积，部分学习状态还能延续到下一场次。

这项工作推进了什么 · 这些时间尺度在最终模型之前就由行为数据独立得到，因此多时间尺度记忆本身就是生物学结果，并非为提高拟合而额外增加的复杂度。
问题一次社会结果会影响之后多久？
怎么做分别检验下一次决策、几分钟内的多事件历史，以及跨天连续性。
意味着什么同一套社会学习策略同时使用秒级、分钟级和跨天记忆。
核心问题｜一次社会结果会影响之后多久？数据给出三个可分离尺度：下一次决策的快速调整、约 4.5–7.5 分钟的近期历史，以及延续到下一天且在场次早期最强的短暂先验。
一次结果会立即重设下一步社会信息需求
结果立刻改变是否继续找信息

相对未奖赏，主动成功使下一次重新启动观察下降 9.0 个百分点，被动结果下降 8.3 个百分点；在学习者中，主动成功驱动的快速切换效应从训练早期 4.3 增至晚期 10.8 个百分点（P=.041）。

近期社会经历会被连续整合
分钟级记忆

最佳记忆衰减范围对应约 20–33 个事件，也就是约 4.5–7.5 分钟；多事件历史明显优于单一指数衰减轨迹。

部分学习状态延续到下一场次
跨天记忆

真实日期顺序优于 500 次同一动物内的日期打乱；保留前一天先验后，29/40 动物的预测改善。

秒级效应的生物学含义｜结果会立刻改变“还需不需要继续从同伴那里取样”。未奖赏保留了继续寻求社会信息的需求，得到主动成功或被动结果后则暂时降低再次采样；这条快速规则还会随学习增强。分钟级历史和跨天先验继续在更慢时间尺度上塑造同一采样策略。
核心计算模型

一个紧凑的社会学习模型解释小鼠何时主动获取社会信息，以及经验如何改变采样策略

SLM 把当前状态、近期社会经历、采样策略和结果特异的社会归因压缩成一组可由神经记录和因果实验继续检验的变量。

这项工作推进了什么 · 这项工作的核心贡献是把行为描述推进为机制变量：同一组计算既解释选择，又能够继续检验 VTA、JAWS 和生成式智能体是否实现这些步骤。
问题什么样的紧凑计算能解释这些选择？
怎么做从简单基线和经典强化学习模型逐步比较到默认 SLM；灵活模型只用于评估预测容量上限。
意味着什么SLM 保留接近上限的预测能力，同时留下可直接进行神经和因果检验的变量。
先分清三个层次。 函数形式看线性/逻辑回归还是非线性/循环网络；学习架构看模型内部维护什么状态，例如经典价值、选择惯性、结构化 SLM 状态或数据驱动潜在状态；计算读出看某个时间点读取采样策略、APE、RPE 或社会结果归因。三者回答的问题不同，不能混成同一个模型列表。
0 · 直接读出

基础发生率 / 时间进程 / 当前状态线性或非线性读出

原理：直接由可观测当前状态预测选择，不维护学习状态。

关键参数：截距、特征权重、训练数据内选择的正则化；非线性版本额外允许特征交互。

用途：建立没有学习规则时的预测基线。

1 · 经典学习规则

RW / WSLS / Q 学习 / 非对称 Q / 遗忘 Q / 选择惯性

原理：维护少量价值或选择惯性状态，并在选择或结果之后更新。

关键参数：学习率 α；需要时加入折扣/价值项 γ；非对称 Q 使用正负结果各自的学习率；遗忘 Q 加入遗忘率；选择惯性包含衰减和权重。

用途：提供奖赏学习和重复选择倾向的可解释替代模型；Q 系列在结果后产生 RPE。

2 · 机制假说

SLM 组成模块 → SLM 核心 → 默认 SLM

原理：当前状态和多时间尺度记忆共同决定观察策略；采样动作后产生 APE；结果出现后更新来源/结果特异的社会归因和价值。

关键参数：多时间尺度状态及衰减、策略读出权重、社会归因和价值学习项；默认行为 SLM 再加入通用选择惯性分支。

用途：作为主要机制模型；策略、APE、社会归因和价值在 VTA 与 JAWS 检验之前已经定义。

3 · 灵活非线性对照

历史多层感知机（MLP） / 完整历史 MLP / 小型循环网络（TinyRNN） / 线性动态网络（LDN）

原理：不预设 SLM 语义，自由学习非线性历史交互。

关键参数：隐藏层或循环网络权重、隐藏维度、正则化和训练超参数，全部只在训练数据内选择。

用途：作为容量上限和压力测试，检验通用记忆与非线性是否足以解释同一行为。

4 · 动力学模型

社会世界模型（SWM）

原理：不提供 SLM 方程，直接学习循环潜在状态来预测未来行为和社会动力学。

关键参数：编码器、循环潜在动力学以及未来状态/行为读出，端到端训练。

用途：检验与 SLM 对齐的坐标能否自行出现，并寻找 SLM 没有显式包含的前瞻性社会效益状态。

行为比较约定。 主要紧凑模型比较固定同一批 27 只留出动物、同一预测目标和逐动物留出评估；Brier 作为主要概率校准指标，AUC 和对数损失作为辅助。经典强化学习模型使用较窄的状态输入；检验“相同当前输入下 SLM 结构是否仍有价值”时，强对照复用同一当前状态骨架。多层感知机和循环网络只作为容量上限，不直接获得机制解释。
后文统一术语。 采样策略是结果出现前选择观察的概率或规则。动作预测误差（APE） = 实际采样动作 − 动作前采样概率，在采样动作发生后、当前社会结果可用前计算。奖励预测误差（RPE）是结果后的奖赏/价值预测误差；Q 学习中 δ = r + γV′ − V。社会结果归因是结果出现后、带有信息来源和结果类别标签的更新。这些量属于不同时间点的计算读出。
