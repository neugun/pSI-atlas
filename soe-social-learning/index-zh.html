从观察到行动：动物如何主动采样社会信息，并把它变成自己的行为

SOE 研究动物如何判断什么时候值得看别人、从观察内容中提取可用信息、把信息转成自己的行动，并把结果归因给不同的社会来源。SLM 把这条链拆成可以预测、可以在 VTA 中读取、可以被 JAWS 选择性破坏、也可以装进人工 agent 的计算变量。

核心计算模型

默认行为模型定义为 SLM mechanistic state + generic choice persistence

SLM 的目标是用紧凑、可实验检验的变量解释社会信息采样。choice persistence 吸收通用 serial choice bias，保留在默认行为模型中；policy、APE、source-specific credit 与 value 构成机制核心。

SLM 回答什么问题｜SLM（Social Learning Model）描述 current state、memory、社会信息采样和 outcome-specific credit 如何共同决定未来选择。行为预测使用 default SLM = mechanistic SLM + choice persistence。神经和因果检验读取 mechanistic core。full-history MLP 只承担 high-capacity ceiling audit，不再作为定义 SLM 价值的参照系。

数据驱动的独立验证与扩展

SWM 把共同的决策坐标与新的 prospective social-efficacy state 分离出来

SLM 从 current state、policy 和 social credit 等明确假说出发；SWM 则在没有写入这些 SLM 方程的条件下学习行为序列。严格检验包括三步：SLM-like coordinates 是否可读取、这个 subspace 是否具有选择性的行为功能、以及 SWM 是否还包含 SLM coordinates 没有覆盖的社会信息。

什么证据才算独立验证｜decoder 本身证据等级有限，因为 raw encoder 与 PCA-compressed encoder 同样可以恢复 SLM variables。更强的检验是从 held-out SWM latent 中删除 SLM-coordinate subspace，并与 matched random subspace 比较行为损失。另一个 prospective-efficacy axis 则单独接受 current-cue baseline 与 social-content perturbation 检验。

神经实现

单一 RPE 可以解释 outcome 后的一部分 DA；完整 Observe episode 还包含 sampling policy、APE 和 post-outcome credit

关键证据来自时间顺序。Early 与 Middle 都发生在 social outcome 可用之前；reward prediction error 与 social-credit update 只有在 outcome 出现后才被定义。

三个 readout 的定义｜Actor 先给出 Observe 的 pre-action probability。APE = actual sampling action − pre-action policy probability，描述实际采样动作相对预期倾向的偏差。观察结果出现后，reward/value 与 source-specific social credit 才开始更新。这三个 readout 对应一次 Observe episode 中连续发生的计算。
