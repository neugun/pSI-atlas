# SOE × SLM × VTA — mobile result portal

This directory is the mobile-first result portal for the Social Observational Eating project.

The page is organized by scientific discovery rather than a fixed figure count:
behavioral phenotype → adaptive social-information value → SLM prediction → native Observe-to-Feed conversion → artificial-agent generative sufficiency → VTA temporal adjudication → Visual Block / JAWS causality → generalization → cross-task/species evidence → claim boundaries.

Current authority date: 2026-10-04.

Open `index.html` through GitHub Pages. Exact numeric authority is preserved under `docs/` and `data/`.
