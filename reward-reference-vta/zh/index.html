近期奖赏历史会改变同一种食物在VTA多巴胺中的表征

这个项目问的是一个很直接的问题：同一种食物，在动物刚刚经历过不同奖赏之后，VTA多巴胺反应还会不会一样？ 答案是不一样。即使当前吃到的是完全相同的20E或100E，前面吃过什么仍然会改变持续性的VTA多巴胺信号，也会改变动物继续吃下去的倾向。 我们用一个简单的“参照值”来描述这种历史影响：过去真正被动物采样过的奖赏会逐步形成一个内部参照 R， 当前奖赏 U 则相对于这个参照被评价，得到 C=U−R。 这个历史相对值不是在舔第一下之前就固定出现，而是在持续进食过程中逐渐变得更明显；与此同时，舔舐和当前采样本身也强烈贡献于VTA多巴胺。 因果实验进一步说明，当前进食时的VTA多巴胺确实控制进食是否继续；但过去的刺激历史可以影响之后的多巴胺，而不一定足以改变之后的进食时长。

已经建立的核心结果

物理上相同的食物，在不同历史后诱发不同的多巴胺和进食反应（9/9 只动物，图 1）。真实采样历史携带超越当前食物的信息（图 2、图 3–4）。进食持续期的相对价值系数在 11/11 只动物增强（图 5）。急性操纵 VTA 多巴胺可改变进食终止概率（图 7）。

不能过度推广的结论

神经历史表征不等于必然影响行为。Stim13 的神经历史显著，但进食时长的边际历史效应尚未成立。Natural、QE、Stim13 尚不能共同证明一种独立于近期局部历史的普遍深层行为门控。31 类模型库包含真实检验、不可辨识边界和模拟恢复，不能全当作同等级真实数据拟合。

必须纠正的计算问题

C=U−R 不是独立于 U、R 的第三个自由变量；线索 RPE=U−E 也一样。应该独立操纵采样历史、明确的线索期待和实际奖赏，再比较受约束的 C 模型、线索 RPE 和扩充状态 TD/RNN。相同的物理探针也不能排除所有包含历史状态的广义 RPE。

当前故事在 多巴胺 理论中的位置

最重要的延伸不是“多巴胺不是奖赏预测误差”，而是：多巴胺进行价值比较时所依赖的内部状态，本身会被近期真实采样过的奖赏历史动态塑造。

Uchida–Gershman 这条工作线不断把 多巴胺 理论 从“固定、可直接观察的 状态”推进到“动物内部推断出的、任务-依赖 的 状态 表征”。 奖赏对比沿着同一逻辑继续推进到持续进食：近期 采样 的 奖赏 建立一个连续 参照值 R， 因而完全相同的当前 奖赏 U 会获得不同的 神经 与 行为 意义。

奖赏对比

近期进食历史本身就是一种内部状态变量

我们的结果提示，在 持续进行的 进食 中，相关 状态 并不能只用 线索、区块 身份 或 离散 信念 描述。动物此前真正吃到了什么，会连续地建立 参照值 R。

当前故事用一句话概括

进食期间的VTA多巴胺是在一个由历史塑造的内部状态空间中表征当前奖赏： 过去真正 采样 过的 结果 建立 参照值 R；当前 奖赏 U 相对于这个 参照值 被重新评价； 这个 历史-相对 信号 在 持续性 进食 中尤其清楚，并参与决定动物是否继续吃。

整合模型：已采样 历史 → 潜在 参照值 R → 进食中的当前/参照值 比较 → 持续性 VTA 多巴胺 → 进食持续性。

1. 当前奖赏相同，但内部参照不同

H 对比 S、L 对比 N 把当前 食物 固定，只改变 近期 奖赏 历史。匹配的当前 效应 同时出现在 持续性 VTA 多巴胺 与 进食持续性。

2. 参照值依赖真实采样，而不只是情境

历史-相关 结构 在 进食 真正开始后增强。单纯 elapsed clock 时间 或 离散 任务 状态 因而不足以描述 持续进行的 多巴胺 所需要的 潜在 变量。

3. 这个信号直接连接正在进行的行为策略

进食-时期 多巴胺 操纵 会改变 进食段 终止 / 持续性。因此 奖赏 历史 不只是改变一个 回溯性 神经 code，而是在改变当前 奖赏 的 行为 意义。

经典 TD / 信念-状态 view δt = rt + γV(bt+1) − V(bt)

Uchida/Gershman 最重要的启发是：多巴胺 误差 依赖动物内部的 表征 b，而不是只依赖实验者看到的 stimulus。

奖赏对比 对 状态 表征 的扩展 Rt+1 = Rt + α(Ut − Rt)   ；   Ct = Ut − Rt

我们的核心主张是：近期 consumed 结果s 为内部 状态 增加了一个连续 坐标 R。多巴胺 可能直接表征 C，也可能是在一个包含 R 的 augmented 状态 上计算 广义 预测 误差。当前数据建立了“历史 必须进入 状态”；下一批 fully-crossed experiment 才真正区分这两种 implementation。

现在真正剩下的机制分叉

现代 多巴胺 理论 允许两个都很严肃的 implementation。当前数据已经识别出“缺失的 状态 变量”——已采样 奖赏 历史——但还没有资格强行二选一。

模型 A

Augmented-状态 广义奖赏预测误差

learner 的 隐藏 状态 中包含 近期 已采样 历史 R。多巴胺 仍然是 广义 TD / 预测 误差，只是这个 误差 不再在 线索、时间 或 区块 身份 这种贫乏 状态 上计算，而是在包含 R 的 richer 状态 表征 上计算。

关键预测：如果给 learned-状态 TD/RNN 足够的信息去推断 R，那么它应当能够吸收 匹配的当前 历史 效应。
模型 B

持续性 参照值-相对 状态 / 对照模型 信号

近期 历史 在 进食段 前建立 参照值；当前 奖赏 真正被 采样 后，持续进行的 多巴胺 信号 本身持续携带 当前 奖赏 U 与 参照值 R 的 有方向 比较。

关键预测：即使经过行为验证的线索期待使线索 RPE 很小，相同的当前探测奖赏仍可能因历史不同而在持续摄食期分离；这不排除历史相关的广义 RPE，而且该 信号 会因果改变 持续性。
当前数据已经决定的：内部 状态 description 必须保留 近期 已采样 历史。
当前数据还没有决定的：持续性 VTA 多巴胺 究竟是 augmented 状态 上的 广义 预测 误差，还是一个不同的 持续进行的 对照模型/状态 信号。
决定性实验：fully cross 历史 × 当前 奖赏 × 显式 expectation；在同一细胞中分别比较 线索 / first-采样 / 0–2 s 与 持续性 2–5 s，再用 留出验证 trial 直接竞争 augmented-状态 TD/RNN 与 显式 C=U−R 模型。
这个 framing 很关键。 最强的说法不是 奖赏对比 “推翻 RPE”。 更准确、也更强的说法是：对 持续进行的 进食 而言，observable-状态 / 线索-仅 RPE 不完整。 一个成功的 多巴胺 理论 必须解释：为什么完全相同的当前 奖赏 在不同 已采样 历史 后产生不同 持续性 多巴胺； 为什么 累积 历史 在 信念/HMM/奖赏-率/循环 alternatives 之后仍保留独立信息； 以及为什么这个 神经 状态 会改变 行为 持续性。
当前 模型 zoo 在这个故事里各自负责排除什么

信念 / HMM：检验 隐藏 离散/任务 状态 是否已经足够。它们 原始 预测 可以很好，但不能完全吸收 累积 已采样-历史 信息。 经典 TD/RW-RPE：提供 actual-minus-expected 的核心计算，但在当前 状态 表征 下不足以解释全部 持续性 历史 效应。 Pearce–Hall、Kalman、不确定性：检验真正隐藏的变量是不是 学习-率 适应 或 不确定性。 奖赏-率、多时间尺度：检验它是否只是 running 平均 或 generic 时间 integration。 价值-RNN：给 flexible learned 循环 状态 最强机会，看是否无需显式 参照值 也能吸收效应。 无符号 显著性：检验真正重要的是 有方向 相对 价值 还是纯 变化幅度。 因此保留完整 模型 zoo 的目的不是做一个“谁 原始 预测 第一名”的排行榜，而是逐个追问：给每种替代解释最强机会以后，哪些 信息 仍然是必须的。

实验的关键，是把“当前正在吃什么”和“刚才吃过什么”分开。

下面先把页面中最容易混淆的实验缩写和模型变量定义清楚。 最重要的一点是：R 是储存的参照值，而 C=U−R 才是当前奖赏相对这个参照的相对值。

术语具体定义这里如何使用
100E / 20E E = Ensure。100E 是原浓度Ensure；20E 是稀释到原浓度20%的Ensure。 它们分别作为高奖赏和低奖赏液体食物。“100/20”指的是Ensure浓度，不是模型中的价值数值。
奖赏 区块 在变量 实验场次中，100E和20E每120 s切换一次。不同采集批次起始区块的高低奖赏顺序并不完全相同，重建时已显式校正。 如果一个进食段跨越120-s切换边界，则整个进食段被剔除，而不是在边界处强行切成两个进食段。

补充：模型与统计术语
奖赏预测误差（RPE）实际获得的奖赏与动物在当前内部状态下所预期奖赏之间的差值。这是最重要的替代解释之一。本项目并不是否定RPE，而是检验：计算RPE时使用的内部状态，是否必须包含近期真实采样过的奖赏历史。
时间差分学习（TD）一种强化学习规则，用连续时刻之间的预测误差更新价值估计。它是经典多巴胺-RPE理论的计算基础。“广义TD”指的是在更丰富的内部状态上计算误差，而不只依赖眼前线索或区块标签。
潜在状态 / 隐藏状态无法仅从当前感觉输入直接知道、必须结合过去经历推断的内部任务状态。近期真实采样过的奖赏历史，可能正是这种隐藏状态的一部分。
信念状态动物不是确信自己处于某一个隐藏状态，而是对多个可能状态各自保留一个概率。用于检验“对任务状态的不确定性”能否替代显式的历史参照值。
隐马尔可夫模型（HMM）假设不可直接观察的状态会随时间转换，并产生当前可观察结果的一类模型。它提供较灵活的离散潜在状态解释。预测得好并不等于大脑真的实现了一个HMM。
平均奖赏率模型持续估计单位时间或单位经历中平均得到多少奖赏。用于检验历史效应是否只是一个普通的滑动平均，而不是“当前奖赏相对于参照值”的比较。
Pearce–Hall模型一种联结学习模型：越意外的结果，会越明显地改变下一次学习的强度。用于检验真正重要的隐藏变量是否是“学习率会不会自适应改变”，而不是参照值本身。
卡尔曼模型根据旧估计与新观测各自的不确定程度，对内部状态进行加权更新的状态估计模型。用于检验“不确定性加权更新”能否吸收历史效应。
循环神经网络 / 价值-RNN循环神经网络（RNN）具有内部记忆，可从序列中学习一个高维状态；价值-RNN进一步让这个状态服务于价值预测。用于检验一个灵活的高维记忆是否能够在不显式定义一维参照R的情况下解释数据。
无符号显著性只关心变化有多大，而不关心变化是“更好”还是“更差”。它与有方向的相对价值不同；如果信号只是显著性，那么同样大小的正向和负向变化应产生类似反应。
留出预测模型在没有参与拟合的动物或试次上进行预测。用于检验泛化能力并减少过拟合；它不同于在同一批数据上计算拟合优度。
交叉验证 / 逐只动物留出交叉验证反复在一部分数据上拟合、在另一部分上测试；逐只动物留出（LOAO）指每次完整留出一只动物。用于比较模型能否跨动物泛化。
独立增加的ΔR²在其他比较变量已经进入模型后，再加入某个变量所带来的额外解释方差。回答“这个变量在替代解释之外是否还增加信息”，不能和单纯的预测排名混为一谈。
普通最小二乘 + 按动物聚类标准误普通最小二乘用于估计回归系数；按动物聚类的标准误允许同一只小鼠内部的多个进食段彼此相关。这样可以使用进食段级数据，同时仍把“动物”而不是“每个进食段”作为生物学重复层级。
终止风险 / 风险比终止风险表示一个正在进行的进食段在当前时刻结束的瞬时概率；风险比比较两个条件下这种概率的相对大小。用于把多巴胺操纵直接转化为“动物是否更容易停止进食”的行为量。

pSI（后部无名质）与觉醒和攻击相关行为控制有关的前脑区域。未来社会奖赏实验中把它当作“行为阈值探针”，而不是预先假定为社会奖赏价值的来源。

EASI/EASEQ-FISH在功能记录后进行的多重RNA原位成像方法。用于把已知功能的神经元对应到分子标记，并在可能时加入投射身份。

补充：误差指标与统计检验
平均绝对误差（MAE）/ 归一化MAE平均绝对误差是“预测值与真实值之差的绝对值”的平均。归一化或相对MAE再除以一个基线模型的误差，因此1表示“和基线一样”，小于1表示预测更好。用于比较留出数据上的预测能力。预测误差更低，并不等于已经证明某一种生物学机制。
均值标准误（SEM）/ 置信区间SEM表示动物均值估计的不确定程度；置信区间表示在指定统计模型下与数据相容的一段参数范围。它们描述的是估计的不确定性，不等于单个试次本身有多分散。
置换检验在实验设计允许的范围内反复打乱标签或对应关系，构造“没有真实效应”时的零分布。当重采样比简单的正态分布假设更可靠时，用它计算显著性。
Wilcoxon配对秩和检验一种不要求正态分布的配对检验，判断同一动物前后或两个条件之间的差值是否系统性偏离0。适合动物数较少的配对比较；统计单位仍是动物，而不是把每个进食段当作独立动物。

“R系数为负”和“约3 s后系数变正”说的不是同一个变量。

R 是储存的 参照值。控制当前奖赏 U后，R越高，持续性VTA多巴胺越低，因此R可以有负系数。 约3 s后逐渐变正的，是C=U−R的系数。 旧文档中的 RWstate 也是C，而不是R：在192个符合条件的 进食段、11只小鼠中， βC=+2.283（按动物聚类 ordinary least-squares 回归，P=.00171）。 所以固定U时，“C正向”与“R负向”本质上是在描述同一种opponent 几何结构。

两组U/R系数来自不同模型，绝对值不能直接比较。

在把U和R分别z-score后的two-predictor 模型中，持续性多巴胺的系数为 U=+.762，R=−.721（192个符合条件的 进食段，11只小鼠；按动物聚类 OLS；P=.00216和.0282）。 后来的行为-adjusted 模型加入早期及同步舔舐项后，使用原始-scale U/R，得到 U=+.815，R=−2.211（同一11只小鼠；P=8.6×10−5和.00153）。 这两个模型的scale不同，而且都没有强制 βU=−βR；只有直接使用C=U−R时才施加这种等幅反向关系。

进食段开始前C为负，不代表当前食物具有“负价值”。

在第一下舔舐之前，模型已经知道当前区块是哪种奖赏，但动物尚未真正采样当前食物。 此时C与进食段开始前 VTA 多巴胺呈负关系（β=−.485；11只小鼠；按动物聚类 回归，P=.000235）。 因此更合理的解释是：进食段开始前信号反映历史/情境形成的准备状态， 而不是负向 预测 误差，也不是说明当前食物本身具有负效用。

不同实验有些使用同一批动物，因此“不同实验”不等于“独立动物”。

意义直接鉴别 R 是 event-integrator、被动 潜在 状态、physiological 适应，还是 fast + slow 记忆 hierarchy。
3. 奖赏相对价值 vs. 经典 RPE：在同一只动物里拆开两种多巴胺计算
设计用独立训练的线索让相同探测奖赏具有可验证的相似期待；线索 RPE 可以接近零，但历史不同仍可使 C 不同。广义状态 RPE 不一定为零；另加意外高/低奖赏和遗漏试次识别它。
时间分辨分别看线索、第一次采样、0–2 秒、持续性 2–5 秒和进食段结束后，而不是把多巴胺压缩成一个数。
预测RPE 型细胞应对意外结果反应更强，并在结果被预测后减弱；相对价值型细胞则应在两个同样可预测、物理完全相同的探测奖赏上，仍因近期 R 不同而分离。
控制加入口腔内给液的机制版本，最大限度降低接近/寻找动作的混杂。
群体 test直接测试早期多巴胺是否更像 RPE，而持续性多巴胺是否更像 C；若成立，则支持多巴胺在不同时间尺度复用不同计算成分。
意义这是把 奖赏对比 放到经典 多巴胺 理论 中最关键的实验。
4. 精炼的社会相对价值：固定雌鼠身份，只改变互动机会
设计雌鼠在 ON 与 OFF 条件下都持续可见、持续存在；ON 允许互动，OFF 只保留暴露。比较 ON→OFF 与 OFF→OFF，以及 OFF→ON 与 ON→ON。

读出approach、investigation、contact attempts、withdrawal/re-approach、USV、redirected aggression/object biting、VTA 多巴胺、pSI activity 与候选 PBN/pSI input。
身份 扩展约30-min 雌鼠 A 历史→雌鼠 A OFF 探测阶段，再做 雌鼠 A 历史→novel 雌鼠 B OFF 探测阶段。
决定性结果雌鼠 感觉 身份 相同，但相同 pSI input 在不同 社会 历史 后产生不同 attack 概率/I50。
意义建立真正的 社会 hedonic-相对价值 类比模型，同时把 社会 价值 与 aggression 诱导 分开。

6. 纵向单细胞 → 分子身份 → 因果检验
当前线索D1–D9 CaRMA 更支持共同 时间/进食 scaffold + 动物-特异 残差 几何结构；D6 奖赏-质量 效应 是 分布式 且存在 舔舐-independent 成分，而 D5/D8 的 concentration/价值 结构 更弱、更不普遍。

Hedonic 相对价值：最干净的实验递进

原始100E/20E和quinine范式已经建立有方向、持续性 进食 相对价值。下一步最有价值的是保持当前 探测阶段完全相同，只操纵此前的奖赏 历史。 过去提出的30-min 基线 → 60-min rich/neutral/lean 诱导 → 30-min 完全相同 8% sucrose 探测阶段尤其适合，因为它直接把参照值与物理刺激分开。 组合-fed/non-oral calorie、线索/timing、locomotion、deprivation与intraoral 控制s可以继续拆开liking、wanting、感觉 适应、satiety和经典 RPE。

社会 相对价值：精炼后的设计与 观察学习 进食 的联系

早期方案把receptive-雌鼠 交互项与pSI 刺激放在同一个区块里，虽然机制上很有意思，但把社会 价值与行为 诱导混在了一起。 精炼后的方案保持雌鼠 暴露不变，只操纵交互项 access。pSI最适合作为submaximal 行为-阈值 探测阶段；既往5/10/20/40-Hz经验可以用于校准，但不应预设一个固定频率。 社会 观察学习 进食则提供了相邻框架：visual access、familiarity、VTA-多巴胺 时间 contingency以及OXT相关社会-状态信号，可以用来测试“observed 奖赏 历史”是否更新同一个参照值 system，还是形成身份-特异 社会 参照值。

Single-细胞：D1–D9 CaRMA 数据真正提示了什么

当前纵向VTA序列包括D1/D2 痕迹 条件ing、D3 100E、D4/D9 20E、D5 100E 对比 20E、D6 100E 对比 100E+3 mM quinine、D7 50E、D8 100E 对比 50E。 现有结果更接近“共同 时间/进食 scaffold + 动物-特异 残差 几何结构”，而不是普遍稳定的concentration-preferring 细胞 类别或经典 line attractor。 奖赏-质量 效应可以是分布式、舔舐-independent，却并不自动产生稳定的单细胞 “相对价值 neuron”类别。

因此下一实验必须先正交化U与R，再用模型 competition给同一神经元分解身份、参照值、相对价值、RPE、显著性、行为与状态-增益。 真正支持“专门分子细胞 类别”的证据需要相同条件的细胞 跨日 stability、匹配的当前 泛化、分子/投射 enrichment以及因果 double dissociation；反之，如果群体 decoder稳定但单细胞 成员归属旋转，则更支持分布式 流形。

下一阶段的边界。 不应把α≈0.15–0.20当作固定 biological 学习 率；不应把持续性 相对价值直接等同于经典 线索 RPE； 不应从群体平均 photometry或当前D1–D9设计宣称普遍“相对价值 neuron”类群；也不应在没有直接证据时把pSI称为社会 奖赏 对照模型。 真正的核心问题是：近期经历如何建立参照值，使完全相同的当前 奖赏获得不同的价值/行为 意义，而这个参照值究竟由专门的分子 细胞 类别还是分布式、状态-依赖 流形实现。

局限与下一步

现在最清楚的是“存在什么计算”，而不是“哪一类细胞在哪里完成了它”。

当前数据已经比较强地限定了奖赏-历史 计算，但还不能把R的储存、C的比较和行为 读出精确落到具体细胞类型或单一脑区。

真正的更新单位还没有完全分开。

prior 舔舐 count和prior 进食 时间在现有任务里高度相关。 下一步需要独立操纵未采样延迟、采样次数和实际摄入量，才能区分舔舐-by-舔舐 更新和integrated 暴露。

VTA群体光纤记录无法告诉我们哪些细胞分别编码U、R、C和行为。

单细胞 recording或imaging可以检验这些成分是否由不同多巴胺 subpopulation携带， 还是由同一细胞在不同时间阶段multiplex。

神经历史痕迹与行为表达需要用更直接的因果实验拆开。

可以分别扰动candidate upstream circuit、VTA本身和downstream 进食 门控， 看哪一步负责存R、哪一步产生C、哪一步把C转换成持续性。

延迟 × 采样实验可以最直接地检验R到底如何更新。

固定奖赏 身份，同时独立改变“没吃时等了多久”“吃了几次”“总共吃了多少”。 如果参照值主要由实际experience更新，那么单纯等待应该很少移动R，而采样 暴露应该产生graded 更新。

内部状态 × 奖赏设计可以区分生理状态究竟作用于U、R，还是作用于最终读出增益。

饥饿、satiety或GLP-1 操纵可以和同一交替 schedule正交组合。 如果内部 状态主要改变当前奖赏 价值，应首先影响U；如果主要改变历史 学习，则应改变R的形成；如果主要改变行为 表达，则可能改变多巴胺-to-持续性 coupling。

是否必须引入更丰富的奖赏群体编码？分布式强化学习、边际效用群体平均光纤信号不需要额外的分布宽度；只有两个物理奖赏水平时也无法独立辨识边际效用。

历史候选算法本身能否被区分？FullHistoryRW、ReferenceRW、BlockSampling、TwoStage、Absolute、OneShot、Clock这些属于模拟/模型恢复层；自身恢复率衡量可辨识性，不能和真实神经数据的留出预测混在一起解释。
