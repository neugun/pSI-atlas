# Reward Contrast Global Research Roadmap

**Version:** 2026-10-06  
**Scope:** synthesis of the Reward Contrast discussion history, current authority analyses, social extensions, hedonic-contrast experiments, longitudinal single-cell work, and next-paradigm design.  
**Use:** research-planning document. Completed findings, preliminary observations, priority experiments, and speculative mechanisms are kept separate.

---

## 1. Research progression

The program has evolved through five increasingly stringent questions.

1. **Does ongoing VTA dopamine encode more than the physical reward currently being consumed?**  
   The original variable-palatability work established sustained consumption-phase VTA dopamine and behavioral contrast across high- and low-value food conditions.

2. **Does recent sampled reward history alter the representation of the same current reward?**  
   Matched-current H/L/S/N analyses and the recursive reference model showed that recent sampled outcomes contribute information beyond current reward, local action, categorical latent state, and several model alternatives.

3. **Is the history signal a classical cue-RPE, an unsigned surprise signal, or a continuously updated reference?**  
   Current authority favors a signed reference-relative signal during sustained consumption. Raw prediction can favor HMM/belief models, but cumulative sampled history retains unique information. Unsigned salience and uncertainty do not absorb the sustained signal.

4. **Does the same computation generalize across reward identity and social reward?**  
   Quinine and stimulation datasets suggest partial transfer of reference memory and dissociation between neural memory and behavioral expression. Social contrast is the major next domain.

5. **How is contrast represented at single-cell and molecular resolution?**  
   Longitudinal 2P/CaRMA data show distributed, animal-dependent coding rather than a simple stable concentration-preferring cell class. The next decisive experiment must orthogonalize current reward, reference history, identity, RPE, salience, and action within the same recorded neurons.

## 2. Current core model

### 2.1 Variables

- **U:** current reward term.
- **R:** stored reference built from previously sampled outcomes.
- **C = U - R:** signed relative-value / reward-contrast coordinate.
- **Behavioral expression:** feeding persistence, termination, re-engagement, action switching, or social-action threshold.

The central conceptual chain is:

**sampled reward history -> reference R -> current-vs-reference comparison C -> sustained VTA dopamine -> action persistence / policy**

This is not equivalent to a classical cue-based RPE. The current data support a history-dependent comparator during consumption, while leaving open how much of R is encoded upstream, locally in VTA, or in distributed loops.

### 2.2 Current authority boundaries

- The fitted alpha around **0.15-0.20** is a useful recency descriptor, not a uniquely identified biological learning rate.
- Raw held-out prediction can favor HMM/belief/reward-rate models, but FullHistory retains unique information beyond those states.
- Sustained 2-5 s dopamine favors **signed contrast** over pure unsigned salience.
- Uncertainty terms have not shown convincing unique explanatory value in the current task.
- The primary two-level task cannot identify nonlinear marginal utility curvature.
- Bulk photometry cannot determine whether the signal is generated by dedicated contrast neurons, heterogeneous threshold/gain populations, or a distributed manifold.
- Current D1-D9 single-cell labels remain exploratory because history and current outcome are not fully orthogonalized in the original alternating design.

## 3. Hedonic contrast: completed foundation

### 3.1 Original variable-palatability paradigm

Core design:
- Alternating approximately **2-min blocks** of high- and low-value Ensure conditions.
- Major conditions included **100% Ensure (100E)**, **20% Ensure (20E)**, quinine-adulterated Ensure, and VTA-dopamine activation manipulations.
- Positive contrast prolonged feeding; negative contrast shortened feeding.
- VTA dopamine showed sustained, graded consumption-phase contrast rather than only cue-locked prediction signals.
- Earlier work also suggested temporal persistence/discounting over much longer intervals, motivating explicit seconds-to-hours tests.

### 3.2 Matched-current history test

H/L/S/N logic:
- **H:** 100E in a stable high-reward context.
- **S:** 100E in the alternating context.
- **L:** 20E in a stable low-reward context.
- **N:** 20E in the alternating context.

The key logic is that **H vs S** and **L vs N** hold the current food constant while changing recent history.

This was the conceptual pivot from “palatability coding” to “reference-dependent valuation.”

### 3.3 Sampling, not passive time, updates the reference

Current authority separates:
- elapsed time after a block transition,
- recent lick amount,
- recent feeding duration,
- sampled reward sequence.

Before the first sample in the new block, elapsed clock time contributes very little. Once the animal consumes, lick and feeding-history terms become informative. This supports a **sampling-integrated reference update** rather than a purely passive temporal clock.

## 4. Hedonic contrast: priority new paradigms

### 4.1 Acute 2-min transition paradigm

Purpose: measure the fast emergence and sign of contrast while matching the current outcome.

Food transitions:
- **H -> L vs L -> L** for negative contrast.
- **L -> H vs H -> H** for positive contrast.

Recommended analysis windows from prior planning:
- **-30 to 0 s**
- **0-10/20 s**
- **0-30 s**
- **30-90 s**
- **90-120 s**

Primary readouts:
- VTA dopamine,
- bout initiation,
- bout duration,
- lick-rate adaptation,
- pause structure,
- re-engagement,
- inter-bout intervals,
- termination hazard.

Reason: this design directly separates transition-triggered contrast from the absolute value of the current reward.

### 4.2 Sustained history -> current probe

Food:
- approximately **30 min high-history -> low probe**
- matched **30 min low-history -> low probe**
- reciprocal positive-contrast version where feasible.

Post-switch windows:
- 0-30 s
- 30-120 s
- 2-5 min
- 5-10 min
- 10-20 min
- 20-30 min

Purpose:
- estimate persistence and recovery,
- distinguish fast dopamine dynamics from slower reference-state dynamics,
- test whether contrast decays continuously, collapses after resampling, or shows multiple timescales.

### 4.3 Same-physical-probe induction paradigm

A particularly clean design proposed in prior chats:

1. **30-min baseline**
2. **60-min reference induction**
   - rich: e.g. 32% sucrose
   - neutral: e.g. 8% sucrose
   - lean: water or approximately 1-2% sucrose
3. **30-min identical 8% sucrose probe**

Key point: the physical probe is identical, but its recent reference differs.

Readouts:
- first-lick latency,
- acceptance,
- bout size,
- lick microstructure,
- pauses,
- re-engagement,
- seeking versus consummatory components,
- switching away from the probe,
- VTA dopamine and downstream policy signals.

Controls:
- matched access,
- matched cues and timing,
- caloric/satiety matching,
- pair-fed or non-oral calorie controls,
- deprivation state,
- locomotion,
- sex/estrous and strain where relevant.

This is one of the strongest future paradigms because it removes the major identifiability problem of alternating high/low outcomes.

### 4.4 Contrast versus classical RPE

Use contexts that all predict the **same expected probe** so that:
- expected same probe: approximately delta = 0 but C differs because R differs,
- unexpected high/low catch probes: delta != 0.

Add:
- intraoral delivery to reduce seeking/action confounds,
- expected and unexpected probe trials,
- reward omission where appropriate,
- cue-matched control trials.

This directly separates:
- current value,
- reference contrast,
- classical RPE,
- unsigned surprise,
- action-related persistence.

### 4.5 Positive-negative asymmetry

Test separately:
- high -> low,
- low -> high,
- gain and loss channels,
- recovery after each direction.

Questions:
- Are positive and negative contrast equal in magnitude?
- Are they carried by the same cells?
- Do they have the same time constant?
- Do they map symmetrically onto behavior?

Prior model-zoo work already motivates explicit asymmetric-update models; the experiment should test this biologically rather than only computationally.

### 4.6 Reward identity and generalization

Test same/reference computations across:
- sucrose,
- Ensure,
- fat,
- protein,
- salt,
- bitter/quinine conditions,
- social rewards.

Core question:
- Is there a shared relative-value axis?
- Or are there identity-specific references that converge only at an action/policy stage?

A useful structure is:
- history and probe of the **same identity**,
- history of reward A -> probe A,
- history of reward A -> probe B,
- cross-domain food -> social and social -> food probes.

## 5. History-dependent need contrast

A broader paradigm developed in 2026 was **History-dependent Need Contrast**.

General structure:

**history induction -> identical current challenge -> neural recording -> action readout -> physiological state measurement**

Candidate history manipulations:
- fasting / refeeding,
- sucrose / fat / Ensure / quinine,
- glucose / insulin,
- GLP-1R drugs,
- GIP / amylin,
- gastric or vagal manipulations,
- CGRP/PBN aversive history,
- obesity / diabetes,
- chronic stress / inflammatory state,
- social isolation or social enrichment.

The conceptual goal is to ask whether internal state changes:
- current utility U,
- stored reference R,
- update rate,
- positive/negative asymmetry,
- comparator gain,
- action cost,
- identity weighting,
- or the translation from neural contrast to behavior.

This is important for obesity and anhedonia because those conditions may not simply reduce reward magnitude. They may alter **reference formation**, **contrast gain**, or **contrast-to-action transfer**.

## 6. Social contrast: evolution of the paradigm

### 6.1 Original 2025 social-contrast idea

Male mice alternated every approximately 2 min between:
- receptive-female prosocial interaction,
- the same female context paired with optogenetic pSI stimulation that could evoke attack/biting.

Preliminary observations included escalated biting toward animals and even inanimate objects after frustration-like manipulations.

This version was mechanistically provocative but confounded:
- social reward value,
- pSI stimulation,
- action induction,
- threat/aggression.

### 6.2 Refined social contrast design

The cleaner 2026 formulation is:

- The **female remains exposed in both conditions**.
- **ON:** social interaction is available.
- **OFF:** exposure remains, but interaction is blocked.

This isolates access/interaction value while preserving the sensory identity of the female.

Acute transitions:
- **ON -> OFF vs OFF -> OFF**: negative social contrast.
- **OFF -> ON vs ON -> ON**: positive social contrast.

The pSI manipulation should be used as a **submaximal action-threshold probe**, not as the source of social value.

This refinement is critical. It makes pSI a readout of how prior social history changes aggression/action threshold rather than confounding the induction of the reference itself.

### 6.3 pSI calibration

Prior planning emphasized submaximal stimulation:
- avoid ceiling attack probability,
- calibrate a stimulation-response curve,
- earlier experience included 5/10/20/40-Hz ranges.

Useful pSI readouts:
- attack probability,
- attack latency,
- duration,
- I50 / threshold,
- slope of the input-output function,
- investigation,
- withdrawal/escape,
- redirection toward nonsocial objects.

### 6.4 Sustained social history -> current probe

Priority design:
- approximately **30 min female-A interaction ON history -> OFF probe**
- matched **30 min female-A OFF history -> OFF probe**

Then test identity generalization:
- Female A history -> **novel Female B OFF probe**

Interpretation:
- same-female transfer indicates stored social reference,
- novel-female transfer tests whether the reference is identity-specific or a generalized social-value state.

### 6.5 Social readouts

Behavioral:
- approach latency,
- investigation duration,
- contact attempts,
- withdrawal,
- re-approach,
- USVs,
- preference,
- aggression threshold,
- pSI-evoked attack I50,
- redirected aggression / object biting.

Physiological:
- pupil,
- heart rate / HRV,
- corticosterone / ACTH,
- glucose / insulin where relevant,
- locomotion/arousal.

Neural:
- VTA dopamine,
- pSI,
- PBN inputs,
- potentially BLA/OFC/vH/CA2-vCA1/VP/CeA/NAc depending the hypothesis.

## 7. Social observation and observational feeding as a related branch

The social-observation feeding project is not identical to social contrast, but it provides a powerful adjacent framework.

Established / advanced observations from prior work include:
- visual access is important,
- familiarity enhances learning,
- observer VTA dopamine increases during social feeding,
- temporally contingent VTA-dopamine inhibition reduces observational eating,
- replayed/noncontingent inhibition does not reproduce that effect,
- OXT is an important upstream candidate/requirement in the broader social-learning line.

A particularly informative causal design used approximately 1-h sessions with alternating 2-min OFF/ON epochs. In the contingent condition, 635-nm light (approximately 10 mW) inhibited VTA dopamine neurons for about 1 s after demonstrator licks, with a brief ramp-off. This reduced the social-reward / observational-feeding index in a small pilot cohort (n=5, P<0.05), whereas replaying the prior-session light timing with matched light exposure did not reproduce the effect. The important conceptual result is therefore not simply “less dopamine means less eating,” but that **the timing of dopamine relative to observed social-reward events matters**.

The broader conceptual sequence from earlier discussions was:
**observe / orient -> approach -> social consumption / action**.
Food or other physiological rewards may act as generalized teaching signals for social observation, but it remains unresolved whether social learning reuses a common physiological-reward currency or relies on domain-specific social currencies such as touch, olfaction, affiliation, reciprocity or status.

Future outcome-manipulation designs:
- demonstrator consumes palatable food,
- demonstrator consumes bitter food,
- demonstrator experiences transient illness,
- observer later receives the same or different food.

Additional readouts proposed for this branch include observer feeding, VTA dopamine, glucose/insulin, pupil, heart rate/HRV, ACTH/corticosterone and inflammatory/cytokine measures. These allow a direct test of whether social reward history changes only neural valuation or also primes autonomic/metabolic state.

This creates a social version of reward-reference learning:
**observed outcome history -> social expectation/reference -> later self-reward or social-action probe**

Candidate pathway:
- visual/SC-related relay -> VTA,
- OXT and other social-state inputs,
- downstream NAc/dorsal striatum for learned action,
- OFC/BLA/pSI for social valuation and aggression-related policy.

The key cross-project question is whether social observation changes:
- the same relative-value axis used for direct consumption,
- an identity-specific social reference,
- or only the policy downstream of reward evaluation.

## 8. Social-circuit hypotheses: keep them explicitly provisional

Several circuit ideas arose repeatedly, but they are hypotheses, not established conclusions.

### 8.1 pSI-VTA negative-contrast loop

Proposed:
- pSI -> VTA contributes to social negative contrast,
- VTA dopamine dips / D2-dependent mechanisms lower pSI attack threshold,
- PBN -> pSI -> VTA may participate in the transition from frustration/negative contrast to aggression.

This needs direct simultaneous recording and causal intervention before being treated as a mechanism.

### 8.2 Candidate hierarchy

Upstream identity / reference candidates:
- MeA / MPOA and social sensory pathways,
- CA2 -> vCA1,
- ventral hippocampus,
- BLA,
- OFC,
- insula.

Contrast-to-policy candidates:
- VP,
- NAc,
- CeA,
- BLA/OFC projections.

Action-threshold output:
- pSI -> PAG and related aggression-output pathways.

A useful principle from prior discussions is that **pSI should be treated as an action-threshold/output probe, not automatically as the social reward source**.

## 9. Single-cell Reward Contrast program

### 9.1 Existing longitudinal 2P/CaRMA sequence

The longitudinal VTA dataset spans multiple reward functions in the same animals/cells.

Key day semantics:
- D1/D2: CS+/CS- trace-conditioning components
- D3: 100E
- D4: 20E
- D5: 100E vs 20E
- D6: 100E vs 100E + 3 mM quinine
- D7: 50E
- D8: 100E vs 50E
- D9: 20E

The scientific goal is a same-cell functional fingerprint across:
- cue prediction,
- consumption,
- palatability,
- reward magnitude,
- contrast/history,
- reward identity.

### 9.2 What the current single-cell data do and do not show

Current analyses suggest:
- a frozen longitudinal authority containing hundreds of cell-level records across the D1-D9 sequence,
- strong common consumption/state components,
- distributed reward-quality effects,
- animal-specific cellular implementations,
- some cross-day stable response phenotypes,
- no simple universal concentration-preferring cell class,
- no general classical one-dimensional line attractor,
- common temporal scaffold plus animal-specific residual geometry.

Several details matter for planning the next experiment:
- D5 (100E vs 20E) did not yield a stable population-level concentration/value axis.
- D6 (100E vs 100E+quinine) produced the clearest reward-quality evidence. In one authority analysis, ANM181 showed a residual sustained effect after lick/trend adjustment (beta approximately +0.084, P approximately .028), while the broader lick-adjusted neural interaction was highly significant in a later cross-animal analysis (P approximately .0008). The effect was distributed rather than supported by a large set of individually FDR-significant cells.
- Raw reward-quality geometry was detectable across animals, but strict residualized crossnobis/geometry was less robust. The safe interpretation is a lick-independent neural component embedded in a behavior-coupled state, not a pure value axis.
- D8 (100E vs 50E) and D5 showed weaker or animal-dependent effects.
- Cross-day whole-vector / response-phenotype stability differed across animals; ANM54 showed clearer continuity than ANM181 in some analyses.
- Reward-manifold work favored a common low-dimensional temporal/consumption organization plus animal-specific residual dynamics rather than a classical causal line attractor.

These results make the next design problem clear: the current dataset contains useful single-cell structure, but its reward-history and current-outcome variables are too correlated to justify stable “contrast-cell” labels.

Important limitation:
the alternating task makes U and history/reference highly collinear, so “contrast cell” labels are not yet strongly identifiable.

This argues for designing the next single-cell experiment around **orthogonalization**, not simply collecting more repetitions of the old schedule.

### 9.3 Decisive next single-cell experiment

Use a **fully crossed history x current-reward design**.

Example logic:
- high history -> high probe
- high history -> low probe
- low history -> high probe
- low history -> low probe

Add neutral history if practical.

Aim for approximately **40-60 analyzable trials per critical cell/condition set** where possible, with enough repeated sessions for stable geometry and cross-day registration.

This design makes U and R independently estimable and allows each neuron to be tested for:
- current reward,
- stored reference/history,
- signed contrast,
- classical RPE,
- unsigned salience,
- action / lick variables,
- identity,
- interaction terms.

### 9.4 Operational single-neuron categories

Do not assign categories from one contrast alone. Use model competition.

Candidate functional components:
1. **identity-like**
2. **current-value-like**
3. **reference/history-like**
4. **signed contrast-like**
5. **RPE-like**
6. **unsigned salience/surprise-like**
7. **action / persistence-like**
8. **state-gain / context-like**

A neuron should be called “contrast-like” only if history explains its response to a matched current probe after current reward, action, local history, and sensory variables are controlled.

## 10. Dedicated cell classes versus distributed manifolds

This is a central question for the single-cell program.

### 10.1 Evidence for a dedicated functional class would require

- reproducible tuning in the same cells across days,
- consistent sign and temporal profile,
- generalization across matched probe identities or contexts,
- molecular enrichment,
- projection enrichment,
- causal perturbation selectively affecting the predicted computation.

### 10.2 Evidence for a distributed manifold would look like

- population-level contrast axis without stable single-cell membership,
- rotation across reward identity/state,
- animal-specific implementation but conserved population computation,
- successful population decoding despite poor neuron-by-neuron correspondence.

The current D1-D9 results are closer to this distributed possibility than to a simple fixed contrast-cell class.

## 11. Function -> molecule mapping

The established technical direction is:

**longitudinal in-vivo activity -> same-cell registration -> ex-vivo EASI/EASEQ-FISH -> molecular / projection identity**

Planned scale from prior proposals:
- adaptive-optics or deep VTA 2P where feasible,
- miniscope fallback for freely moving social tasks,
- approximately 100-gene retrospective molecular panel,
- thousands of VTA neurons across animals,
- rRNA/spatial registration,
- projection information where possible.

Candidate marker families discussed previously:
- food-related: Npy1r, Ntsr1
- social-related: Esr1, Oxtr
- disease / broader program: Syn2 and other ASD-related or state-related markers

The molecular question is not merely “which gene marks reward neurons?”  
It is whether molecular identity predicts:
- reference coding,
- contrast sign,
- reward identity,
- social versus food specialization,
- stability across internal state,
- projection target,
- causal role.

## 12. Cross-domain single-cell test: food versus social reward

A high-value future experiment is to record the same neurons across matched contrast structures in different domains.

Food:
- rich / neutral / lean history -> identical food probe.

Social:
- interaction-rich / neutral / interaction-omitted history -> identical social probe.

Then ask:
- Does a food-derived contrast decoder transfer to social contrast?
- Does a social-derived decoder transfer to food?
- Are upstream identity axes different but downstream relative-value axes shared?
- Are the same cells recruited, or do distinct ensembles converge on a shared action-policy manifold?

This experiment directly connects Reward Contrast, social reward, and the broader function-to-molecule program.

## 13. Disease and state models

The strongest disease/state questions are not simply “is dopamine lower?”

### Obesity / metabolic disease
Possible mechanisms:
- elevated reference,
- compressed contrast,
- altered update rate,
- intact contrast but reduced behavioral gain,
- altered GLP-1-sensitive readout.

### Anhedonia / chronic stress / inflammation
Possible mechanisms:
- impaired reference formation,
- weaker positive contrast,
- excessive negative carryover,
- failure to translate neural contrast into approach/persistence.

### Social isolation / social-deficit models
Possible mechanisms:
- altered current social utility,
- altered social reference memory,
- cue-prediction deficit,
- altered interaction cost,
- intact neural contrast but abnormal aggression/approach policy.

The experiment should distinguish **encoding-state effects** from **probe-state effects** by manipulating state during history induction and during the probe separately.

## 14. Neuromodulator and circuit timescales

Prior planning repeatedly separated:
- fast glutamatergic/GABAergic signals,
- dopamine,
- slower GLP-1 / neurotensin / OXT / cAMP / related modulatory processes.

Priority causal tests:
- boundary-locked perturbation during reference formation,
- perturbation only during the current probe,
- perturbation during the post-switch persistence window,
- projection-specific manipulations.

Candidate circuit chain from the food work:
**periLC current-reward information -> VTA GABA / modulatory integration -> VTA dopamine contrast -> amygdala / reticular / NAc policy and persistence**

This chain should be tested stepwise rather than assumed.

## 15. Proposed execution sequence

### Priority 1 — Fully crossed food history x current reward
Best experiment for causal identifiability and single-cell modeling.

### Priority 2 — Social ON/OFF contrast with female exposure held constant
Best cross-domain extension. Use pSI stimulation only as a calibrated action-threshold probe.

### Priority 3 — Sustained same-probe induction and decay
Best experiment for reference persistence and multi-timescale dynamics.

### Priority 4 — Food/social identity generalization
Same versus novel reward / same versus novel female.

### Priority 5 — Longitudinal 2P/CaRMA + molecular mapping
Separate identity/reference/contrast/RPE/action components at single-cell scale.

### Priority 6 — Need-contrast disease/state manipulations
Obesity, anhedonia/stress, isolation, GLP-1 and related state perturbations after the reference computation is experimentally identifiable.

## 16. Claims that should not be made yet

1. Do not call alpha a biological learning rate.
2. Do not equate the contrast signal with classical cue RPE.
3. Do not claim a universal “contrast neuron” class from current D1-D9 data.
4. Do not claim pSI is the social reward comparator.
5. Do not treat the original pSI-stimulation social paradigm as a clean social-value experiment; the refined exposure-matched ON/OFF design is better.
6. Do not infer nonlinear utility from the current two-level task.
7. Do not interpret bulk photometry as evidence for single-cell efficient coding or threshold distributions.
8. Do not combine model scores from different evaluation protocols into one leaderboard.
9. Do not assume neural reference memory must always produce a measurable behavioral effect; Natural, QE, and stimulation-history datasets already motivate a separation between memory persistence and behavioral expression.
10. Do not force a monotonic dose-response interpretation when descriptive exposure quartiles are non-monotonic.

## 17. GitHub-page take-home

The next phase of Reward Contrast should be presented as a transition from a **bulk history effect** to a **mechanistically identifiable, cross-domain, single-cell reference computation**.

The strongest unifying question is:

> **How does recent experience build a reference that changes the value and action meaning of an identical current reward, and is that reference represented by dedicated molecular cell classes or by a distributed, state-dependent neural manifold?**

That question naturally links:
- hedonic contrast,
- social contrast,
- reward identity,
- longitudinal single-cell imaging,
- molecular mapping,
- disease/state dependence,
- and targeted causal manipulation.
