A new dataset now has a defined entry contract.

Fill two small metadata files, point to TIFF / event / behavior / ROI inputs, then the manager records every stage through per-ROI output and release.

dataset.yaml fixes frame rate, event windows, ROI gates, extraction candidates and condition column.
