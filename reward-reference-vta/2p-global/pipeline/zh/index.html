先把最基础的 neural activity 讲清楚

复杂分析之前，先按照正常 calcium-imaging 文章的顺序展示信号

先给真实连续 fluorescence trace，再给 event-aligned condition average/PSTH、single-trial heatmap、代表性 cell、all-cell heatmap 和 population summary；extraction robustness、cross-day identity、decoding 等全部放在后面。

基本顺序 · continuous trace → event-aligned PSTH → single-trial heatmap → representative cells → all-cell heatmap → population summary → 再进入复杂 QC / model。
单位不混用。 当前 frozen D6 event-aligned authority 是 baseline z，所以明确写 baseline z，不把它伪装成 ΔF/F；连续 trace 显示真实 fluorescence a.u.。后续只要 F0/ΔF/F authority freeze，就应该把 raw fluorescence、ΔF/F、z 并排提供。
