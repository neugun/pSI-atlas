Reward-history experiments during ongoing feeding

Recent reward history changes how the same food is represented by VTA dopamine

We asked a simple question: does the same food evoke the same dopamine signal regardless of what the animal consumed before it? It does not. Matched 20E or 100E rewards produced different sustained VTA dopamine and different feeding persistence after different recent reward histories. A compact reference variable captures this effect: previously sampled rewards update a stored reference R, and the current reward is evaluated relative to that reference as C=U−R. This history-relative signal becomes clearer during ongoing consumption, where it coexists with strong licking and sampling-related signals. Causal dopamine manipulations change feeding persistence, but stimulation history can alter later dopamine without measurably changing later bout duration, separating neural memory from its behavioral expression.

Global progress, evidence boundaries, and the next work

This is the readable on-page overview, not a raw Markdown document. Use the original figures below for evidence and the future experiments section for full designs. Updated code and manuscript audit: October 7, 2026.

Established

History changes responses to physically identical food in 9/9 mice (Fig. 1). Sampling history predicts sustained DA better than current reward alone (Fig. 2; Figs. 3–4). Relative-history coefficients increase during consumption in 11/11 mice (Fig. 5). Acute DA manipulations change feeding termination (Fig. 7).

Boundaries

Neural history is not identical to behavioral expression: Stim13 has reliable neural history but no established marginal duration-history effect. Across Natural, QE and Stim13, a universal local-history-independent deep-reference behavioral gate has not been demonstrated. The 31-family model registry mixes actual tests, boundary cases, and recovery analyses.

Critical model correction

C=U−R is derived, not independently estimable alongside unrestricted U and R; cue RPE=U−E has the same constraint. Cross sampled history, trained cue expectation and delivered reward, then compare constrained C, cue-RPE and augmented-state TD/RNN predictions on held-out data. Identical probes do not eliminate all possible history-aware RPEs.

Where the current story sits in dopamine theory

The key extension is not “dopamine is not an RPE.” It is that the state against which dopamine computes value is itself built from recent sampled reward history.

The Uchida–Gershman line progressively moved dopamine theory from a fixed observable state to an inferred and task-dependent state representation. Reward Contrast extends that logic into ongoing consumption: recent samples create a continuous reference state R, and the same current reward U can therefore acquire different neural and behavioral meaning.

2015–2016

Subtraction is real

Eshel / Uchida: dopamine responses behave like actual-minus-expected reward, and local VTA circuitry contributes expectation-dependent subtraction. The central operation is comparison, not raw reward magnitude.

→
2017–2019

But “expected” depends on inferred state

Starkweather, Babayan, Gershman & Uchida: under temporal/state uncertainty, dopamine reward-prediction errors (RPEs)—the difference between obtained and expected value—are better understood relative to a belief state, meaning the animal’s probability distribution over hidden task states. Gershman & Uchida generalized this into a framework in which state, value and policy uncertainty shape dopamine.

→
2022–2025

State representation explains noncanonical dopamine dynamics

Mikhael / Qian / Uchida / Gershman: ramps, contingency effects and other apparently noncanonical signals can arise when the learner has the right latent-state representation. Recurrent networks can learn such state structure prospectively.

→
Reward Contrast

Recent consumption history is a state variable

Our data suggest that during ongoing feeding, the relevant state is not exhausted by cue, block identity or a categorical belief. What the animal actually sampled before the current bout continuously builds the reference R.

The current story in one sentence

VTA dopamine during consumption reflects the current reward in a history-dependent state space: recent sampled outcomes construct a reference R; the same present reward U is evaluated relative to that reference; the resulting history-relative signal becomes especially visible during sustained consumption and helps determine whether feeding persists.

Integrated model: sampled history → latent reference R → current/reference comparison during consumption → sustained VTA dopamine → feeding persistence.

1. Same current reward, different internal reference

H vs S and L vs N hold the current food constant while changing recent reward history. The matched-current effect appears in both sustained VTA dopamine and feeding persistence.

2. The reference is sampling-dependent, not merely contextual

History-related structure becomes stronger after consumption begins. Elapsed clock time and categorical task state are therefore insufficient descriptions of the latent variable that matters for ongoing dopamine.

3. The signal is tied to ongoing policy

Consumption-period dopamine manipulations alter bout termination/persistence. Reward history therefore does not only modify a retrospective neural code; it changes the action meaning of the current reward.

Canonical TD / belief-state view δt = rt + γV(bt+1) − V(bt)

The important lesson from Uchida/Gershman is that the dopamine error depends on the animal's internal representation b, not only the objectively visible stimulus.

Reward Contrast state augmentation Rt+1 = Rt + α(Ut − Rt)    and    Ct = Ut − Rt

Our claim is that recent consumed outcomes contribute a continuous state coordinate R. Dopamine may represent C directly, or a generalized prediction error computed over a state representation that includes R. The present data establish the necessity of history; the next crossed-history experiments distinguish these implementations.

The remaining mechanistic fork

Modern dopamine theory leaves two serious implementations open. The present dataset identifies the missing state variable—sampled reward history—but does not yet force one of these implementations.

Model A

Augmented-state generalized RPE

The learner's hidden state includes recent sampled history R. Dopamine still reports a generalized TD/prediction error, but that error is computed over a richer state representation than cue, time or block identity alone.

Key prediction: a sufficiently good learned-state TD/RNN model should absorb the matched-current history effect once it has access to the information needed to infer R.
Model B

Sustained reference-relative state / comparator signal

Recent history establishes a reference before the bout, and after sampling the ongoing dopamine signal itself carries a sustained signed comparison between current reward U and reference R.

Key prediction: with empirically matched cue predictions, identical probes can still differ by history during sustained consumption; generalized state-dependent RPE remains an alternative until directly compared.
What the current data already decide: recent sampled history is required in the internal state description.
What they do not yet decide: whether sustained VTA dopamine is a generalized prediction error over that augmented state or a distinct ongoing comparator/state signal.
Decisive experiment: fully cross history × current reward × explicit expectation, then compare cue/first-sample/0–2 s versus sustained 2–5 s responses in the same cells and fit augmented-state TD/RNN and explicit C=U−R models on held-out trials.
This framing matters. The strongest claim is not that Reward Contrast disproves RPE. The stronger and more defensible claim is that standard observable-state or cue-only RPE accounts are incomplete for ongoing consumption. A successful dopamine theory must explain why two physically identical current rewards evoke different sustained dopamine after different sampled histories, why cumulative history retains information beyond belief/HMM/reward-rate/recurrent alternatives, and why this neural state changes action persistence.
How the main comparator models fit into this story

Belief / HMM: important because they test whether hidden categorical/task state is sufficient. They can predict well, but do not fully absorb cumulative sampled-history information. Canonical TD/RW-RPE: provides the core actual-minus-expected computation, but with the current state representation it does not explain the full sustained history effect. Pearce–Hall, Kalman and uncertainty: ask whether changing learning rate or uncertainty is the key hidden variable. Reward-rate and multi-timescale models: ask whether the signal is simply a running average or generic temporal integration. Value-RNN: asks whether a flexible learned recurrent state can absorb the effect without an explicit reference variable. Unsigned salience: asks whether magnitude of change, rather than signed relative value, is sufficient. The reason to keep this full model zoo is not to crown one raw-prediction winner, but to determine what information remains uniquely necessary after each alternative explanation is given its strongest test.

The experiment lets us ask whether the same food is valued differently after different recent histories.

100E / 20E E = Ensure. 100E is full-strength (100%) Ensure; 20E is Ensure diluted to 20% of the full-strength concentration. They are the high- and low-reward liquid foods. “100” and “20” refer to Ensure concentration, not model value.

RPEReward prediction error: the difference between received reward and the reward expected from the animal's current internal state.Used as a major alternative explanation. The negative R coefficient and the positive late coefficient refer to different predictors.

A negative coefficient on R means that, after accounting for current reward U, a higher stored reference predicts less sustained dopamine. By contrast, the coefficient that becomes positive at ~3 s is the coefficient on C=U−R. The previously reported RWstate coefficient is likewise a coefficient on C, not on R: βC=+2.283 in 192 eligible bouts from 11 mice (animal-clustered ordinary least-squares regression, P=.00171). At fixed U, a positive C effect and a negative R effect express the same opponent geometry.

The two U/R coefficient pairs come from different scales and answer different questions.

The standardized two-predictor model gives U=+.762 and R=−.721 in 192 eligible bouts from 11 mice (animal-clustered ordinary least-squares regression; P=.00216 and .0282) after z-scoring U and R separately. The later action-adjusted model gives U=+.815 and R=−2.211 in the same 11-mouse dataset (animal-clustered ordinary least-squares regression; P=8.6×10−5 and .00153) on their raw scales after adding early and concurrent licking terms. Their magnitudes should not be compared directly. The model does not constrain the two coefficients to be equal and opposite; equality is imposed only when a single C=U−R predictor is fitted.

The negative pre-bout C coefficient is a preparatory state, not negative reward value.

Before the first lick, the model can label the upcoming block reward but the animal has not yet sampled that reward. The pre-bout C coefficient is negative (β=−.485; 11 mice; animal-clustered regression, P=.000235), so baseline VTA dopamine is organized oppositely to the later consumption-period contrast. We therefore interpret the pre-bout signal as anticipatory/contextual organization of reward history, not as a negative prediction error or evidence that the current food has negative utility.

Acute stimulation and stimulation history are different questions. Acute stimulation asks what happens while dopamine neurons are being stimulated during the current bout; it directly prolongs feeding. The stimulation-history analysis instead asks whether the pattern of ON/OFF reward samples experienced earlier changes a later bout after current stimulation condition is accounted for. That past history changes later dopamine but does not measurably change later bout duration. This does not conflict with Fig. 1: natural food history changes both the sensory/nutrient reward reference and behavior, whereas an optogenetic history can be stored and read out neurally without necessarily engaging the downstream behavioral gain strongly enough to alter gross duration.
Why this comes first. Before asking what dopamine computes, the task, reward identities, feeding-bout definition, recording location and cohort overlap must be explicit; otherwise later coefficient and causal claims are uninterpretable.

Stable H/L sessions and alternating S/N sessions answer different questions. Figures 2–5 use the alternating sessions; Figure 1 compares stable and alternating contexts while holding current food identity fixed.

Question 1 — is there a history effect at all? Hold the current food constant and change the recent reward context. If dopamine and feeding still differ, current reward alone cannot describe the animal's internal state.
Figure 1

The same food produces different dopamine and feeding after different recent reward histories.

Fig. 1 is intentionally model-free. H and S contain the same 100E reward; L and N contain the same 20E reward. What differs within each pair is the recent reward environment.

Lower recent reward raises the response to an unchanged current reward.

For current 100E, the alternating-session condition follows lower-reward experience and is compared with stable 100E. For current 20E, stable 20E is compared with 20E reached from the higher-reward alternating context. Aligning those two comparisons asks whether the same physical outcome is evaluated relative to its recent range.

Pre-bout and sustained dopamine should be treated as different signals.

The history-aligned effect is not a simple baseline offset carried unchanged into the bout. Pre-consumption dopamine and sustained 2–5 s dopamine have different sign structure, motivating the time-resolved analysis in Fig. 5.

Question 2 — what writes the reference? Once Fig. 1 establishes a matched-current history effect, the next test asks whether that internal reference changes because time passes or because the animal actually samples the new reward.
Figure 2

The reference changes when the animal samples the new reward, not simply because time passes.

Alternating 120-s blocks make elapsed time and reward sampling diverge on the first bout after a switch. This allows a direct test of a passive clock against experience-gated updating.

Before the first new reward sample, passive-time models contributed at most ΔR²=.00385 to sustained dopamine across 9 mice (animal-clustered regression across candidate clock constants; all P>.55). Once sampling began, direct consumption-history terms carried additional information beyond simple bout rank, although the descriptive exposure quartiles themselves are non-monotonic.
Question 3 — is “history” just another name for context or latent state? The model zoo gives belief-state, hidden-Markov, reward-rate, adaptive-learning and recurrent-memory alternatives a direct test. Raw prediction and unique information are kept separate.
Figures 3 and 4

A continuous reward-history variable explains dopamine beyond current reward and simple context labels.

The recursive model uses prior sampled reward identities to build R and then evaluates the current reward as C=U−R. Because current U is already included in the baseline, adding C is equivalent to asking whether stored history R contributes beyond the current reward.

Question 6 — does the signal matter for behavior? Correlation is not enough. Acute and history manipulations test whether VTA dopamine changes bout termination and whether a neural history trace can persist even when a later behavioral effect is weak.
Figure 7

Consumption-period dopamine promotes feeding persistence, while dopamine history can be remembered without changing later feeding.

The causal manipulation and the history analysis answer different questions. Current stimulation tests the immediate contribution of dopamine to persistence; stimulation history tests whether previously experienced dopamine-linked reward samples leave a reference that affects later bouts.

Acute stimulation changes the bout that is being stimulated.

When VTA dopamine neurons are stimulated during ongoing consumption, animals are less likely to terminate that bout. Contingent inhibition shifts persistence in the opposite direction.

Stimulation history changes later dopamine without a stable marginal duration effect.

In Stim13, past ON/OFF reward sampling retained unique information about later dopamine after current stimulation condition, local adaptation and future-history controls (ΔR²=.002524; 13 mice; conditional permutation, P=5×10−5). The corresponding past-history effect on later bout duration was not detected in the same cohort (animal-clustered regression, P=.742).

Fig. 1 and Stim13 therefore address different routes to history-dependent behavior. Natural reward history changes the food-based reference and is expressed in both dopamine and persistence. Prior optogenetic stimulation can be remembered and read out by dopamine while producing too little downstream behavioral gain to shift gross bout duration once the current stimulation condition is accounted for. The independent QE task provides an intermediate case: in 63 same-current 100E bouts from 7 mice, frozen C predicts log bout duration (β=.818, animal-clustered P=.034; within-animal serial-shift one-sided P=.0287), but only 5/6 estimable animal slopes are positive (P=.156), so this behavioral-history result is treated as provisional. A new recency sensitivity analysis makes the reward-class dissociation sharper: Natural history affects both dopamine and duration over a broad moderate-alpha range, whereas Stim13 history changes dopamine at every scanned alpha=.03–.60 but changes duration at none of them (neural BH q<=.0192; behavioral minimum raw P=.682, BH q>=.906). Current-conditioned analyses add an important qualification: Stim13 can show different duration-history slopes under current OFF versus ON, but this interaction is sensitive to recent local-history adjustment (base exact-wild P=.0372; after local-history main effects P=.899; deep-residual interaction P=.154). Thus the current authority is a robust neural history signal without a stable marginal or deep behavioral reference effect, not an absence of every condition-specific behavioral structure.
Why the roadmap follows the results. Figures 1–7 identify a computation more clearly than its cellular implementation. The next experiments therefore orthogonalize U and R, move to social reward and resolve the computation at single-cell, molecular and circuit levels.
Research roadmap

From bulk reward history to cross-domain, single-cell reference computation.

The next phase is not simply “more reward contrast.” It is a set of experiments designed to identify current reward U, stored reference R, signed contrast C=U−R, classical RPE, reward identity, and action policy in the same animals and, ultimately, the same neurons.

What is already established

Recent sampled reward history changes sustained VTA dopamine and feeding even when the current food is matched. Sampling history carries information beyond simple clock time, categorical belief state, unsigned salience and several model alternatives.

The decisive next food experiment

Use a fully crossed history × current-reward design or an identical-probe induction paradigm so that U and R are independently estimable. This is the cleanest way to identify reference, contrast, RPE, identity and action at single-cell scale.

The decisive next social experiment

Keep the female perceptually present while switching interaction ON versus exposure-only OFF. Use pSI stimulation only as a calibrated submaximal action-threshold probe, not as the source of social value.

Detailed future experiments

Each experiment is designed to eliminate one specific ambiguity in the current story.

The priority is not to add conditions indiscriminately: independently manipulate history R, cue expectation E and current reward U, then distinguish constrained C=U−R from cue-RPE and augmented-state alternatives in held-out tests while controlling identity, internal state and action.

Execution order for the next experiments. The next phase should not branch into many unrelated manipulations. First make U, reference-history and cue expectation separately manipulable, and their competing C/RPE models identifiable in one food task; then carry that exact task into longitudinal single-cell recording; only after the food contrast axis is frozen should cross-reward and social transfer be treated as a generalization test.

Priority A — identifiable food contrast

Use a within-animal 2×2 history × current-reward task, add expected identical probes plus unexpected high/low catch outcomes, and analyze cue/first-sample/0–2 s/2–5 s separately. Primary endpoints are sustained VTA dopamine and bout-termination hazard for the same current reward after different histories.

Priority B — hedonic mechanism, not just action

Run the same history manipulation in free feeding and a controlled intraoral/probe version. Lick microstructure, acceptance/rejection, re-engagement and persistence separate consummatory liking-like expression from seeking/action and satiety. The same-probe design is the clean bridge to classical hedonic contrast.

Priority C — single-cell then social transfer

Apply the frozen factorial task to longitudinal 2P/CaRMA, assign cells only by held-out competition among U/R/C/RPE/salience/action/state terms, then test whether the resulting population axis transfers to social-access history and observed-reward history. Cross-domain transfer is evidence only after the food decoder is frozen.

Hedonic contrast: the cleanest experimental progression

The original 100E/20E and quinine paradigms established signed, sustained consumption contrast. The strongest next step is to hold the current probe physically identical while manipulating the preceding reward history. A previously proposed 30-min baseline → 60-min rich/neutral/lean induction → 30-min identical 8% sucrose probe is especially useful because it separates reference from the physical stimulus. Pair-fed/non-oral calorie, cue/timing, locomotor, deprivation and intraoral controls can then separate liking, wanting, sensory adaptation, satiety and classical RPE.

Social contrast: refined design and relation to observational feeding

The earlier social design paired receptive-female interaction with pSI stimulation and was mechanistically interesting but confounded social value with action induction. The refined design keeps female exposure constant and manipulates interaction access. pSI is therefore best used as a submaximal action-threshold probe; earlier 5/10/20/40-Hz experience can guide calibration without fixing a single frequency in advance. The social-observation feeding line provides an adjacent framework: visual access, familiarity, VTA-dopamine contingency and OXT-related social-state signals can be used to ask whether observed reward history updates the same reference system or an identity-specific social one.

Single-cell program: what the D1–D9 CaRMA data imply

The longitudinal VTA sequence spans D1/D2 trace conditioning, D3 100E, D4/D9 20E, D5 100E vs 20E, D6 100E vs 100E+3 mM quinine, D7 50E and D8 100E vs 50E. Current analyses favor a common temporal/consumption scaffold plus animal-specific residual geometry rather than a universal concentration-preferring or classical line-attractor population. Reward-quality effects can be distributed and lick-independent without producing a stable single-cell “contrast neuron” class. The next experiment should therefore orthogonalize U and R before assigning cells to identity-, reference-, contrast-, RPE-, salience-, action- or state-gain components.

The strongest evidence for a dedicated molecular contrast class would require same-cell stability across days, matched-current generalization, molecular/projection enrichment and a causal double dissociation. Conversely, a stable population decoder with rotating or animal-specific single-cell membership would support a distributed manifold.

Important boundaries for the next phase. Do not treat α≈0.15–0.20 as a biological learning-rate constant; do not equate the sustained contrast signal with classical cue RPE; do not infer a universal contrast-cell class from bulk photometry or the current D1–D9 schedule; and do not treat pSI as the social reward source without direct evidence. The central next question is whether recent experience builds a reference that changes the value and action meaning of an identical current reward through a dedicated molecular cell class or a distributed, state-dependent neural manifold.

Limitations and next experiments

The computation is clearer than where and how it is implemented in the circuit.

The strongest unresolved questions concern the microscopic update variable, the cellular locus of the stored reference, and how a neural history signal is converted into behavior.

The microscopic update unit remains unresolved.

Prior lick count and prior feeding time are highly correlated in the current task. An experiment that independently varies delay, number of samples and consumed amount is needed to distinguish lick-by-lick updating from integrated exposure.

Bulk VTA photometry cannot identify which dopamine subpopulations carry each component.

Single-cell recording or imaging during reward switches could separate cells encoding current reward, stored reference, consummatory action and relative value.

Neural readout and behavioral expression need to be causally separated.

Circuit perturbations upstream of VTA and in classical contrast-related regions should test whether reference storage, comparison and persistence are anatomically separable.

A delay-by-sampling experiment would directly test how R is updated.

Hold reward identity fixed while independently manipulating unsampled delay, sample count and sampled volume. The current model predicts little reference movement during unsampled delay and graded movement with experienced reward.

A state-by-reward design would test whether physiological state acts on U, R, or readout gain.

Hunger, satiety or GLP-1 manipulation can be crossed with the same alternating reward schedule. The resulting interaction would distinguish a change in current reward utility from a change in reference formation or downstream expression.

Classical consummatory contrast suggests candidate comparison circuits without establishing identity with the present VTA mechanism.

Classical consummatory successive negative contrast (cSNC) asks how intake changes after an expected high-value solution is replaced by a lower-value one. Lesion work implicates the gustatory thalamus (GT), insular cortex and amygdala-related circuitry in aspects of contrast behavior. Those results motivate circuit hypotheses for reference storage, comparison and affective response, but the present alternating-block task and VTA dopamine signal should not be collapsed into cSNC as if they were the same phenomenon.

A decisive circuit experiment would combine the present reward-history paradigm with temporally targeted perturbation of candidate sensory/limbic nodes while measuring both VTA dopamine and persistence.
