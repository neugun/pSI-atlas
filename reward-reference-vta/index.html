Reward sampling builds a reference; VTA dopamine combines ongoing consumption with history-relative value

The current data support a sequential biological process rather than a single abstract “contrast signal”: experienced reward samples write a persistent reference; current reward and ongoing consumption both contribute to dopamine; and a history-relative U−R component becomes stronger later in the bout. Dopamine then contributes to feeding persistence, while downstream behavioral expression remains context dependent.

Sampled, not clock-only Actual reward consumption updates the reference; passive elapsed time alone contributes little.
ΔR² ≈ .049 Reference remains unique after flexible 0–2 s + 2–5 s action controls (conditional P=.0449).
U ↑ · R ↓ After action control, current reward stays positive and learned reference stays negative in sustained DA.
DA → persistence Activation lowers termination hazard; contingent JAWS inhibition raises it, without proving complete mediation.

The strongest conclusion is therefore not “dopamine is value rather than licking.” It is that consumption-period VTA dopamine multiplexes sampling/action and a learned reward-reference computation. The page below is organized in biological order: reference formation → current sampling → relative-value construction → persistence → context-dependent expression.

Biological sequence

Five steps organize the current result

This order follows the putative biological process, not the chronology of analysis. Each step has a distinct experimental question and a distinct claim boundary.

1 Sample reward

Actual consumption, not passive time alone, provides the experience that can update the internal reward history.

2 Store reference R

Past sampled utilities are compressed into a persistent, recency-weighted reference already present before the next bout.

3 Consume current reward

Current utility and ongoing licking/sampling both contribute to consumption-period VTA dopamine.

4 Construct U − R

A later history-relative component emerges during continued consumption; current reward is positive and learned reference is negative.

5 Express persistence

Dopamine contributes causally to bout persistence, but neural reference expression and gross behavior can dissociate across contexts.

Reference formation
experience-gated

Before the animal samples the new reward, passive-time models add at most ~.004 R². Once the reward is consumed, exposure carries graded update information.

Neural representation
multiplexed

Action contributes substantial sustained-DA variance, but reference remains unique after early, concurrent and even whole-bout sensitivity controls.

Output architecture
shared state · gated readout

Natural reward, quinine and stimulation support transferable history information, while the strength and behavioral expression of that reference depend on context.

Working biological statement: past sampled rewards establish a reference before the current bout; current consumption first recruits a strong sampling/action component; with continued consumption, VTA dopamine additionally expresses history-relative utility; that neural signal contributes to persistence but is not by itself sufficient to guarantee gross behavioral contrast.
Mechanistic architecture

Separate reference formation, current sampling, comparison and behavioral readout

A useful biological model must keep four operations distinct: what the current reward is worth, how previous sampled rewards are stored, how ongoing consumption enters dopamine, and how neural value is converted into persistence or other actions.

H Internal state

Hunger, satiety, illness, GLP-1 state and other physiological variables transform physical reward into current utility.

R Past sampled reference

R is built from previously experienced reward samples and exists before the current bout begins.

A(t) Current sampling/action

Licking and consumption deliver the reward and contribute sensory/motor information to early consumption-period dopamine.

U − R Relative-value readout

Current utility is evaluated relative to stored history; this component becomes stronger later during consumption.

g(C) Output gate

Context and downstream circuits determine how strongly the shared state appears in dopamine, persistence and overt behavior.

Value versus action

What does sustained VTA dopamine represent: value, action, or both?

Licking is not a trivial nuisance variable here. It is simultaneously the route through which reward is sampled, a source of sensory/motor feedback, and a behavioral output that can itself lie downstream of value and dopamine. The correct test is therefore whether current action absorbs the history/reference effect—not whether action correlates with dopamine.

The coupling is real
r = .61

Whole-bout lick count correlates with reference state (r=.611) and sustained DA (r=.392); bout duration correlates with reference state at r=.599. A pure “value versus movement” dichotomy is therefore biologically unrealistic.

Primary neural endpoint
fixed 2–5 s mean

The main action-confound test uses mean DA in a fixed three-second window, not whole-bout AUC. It therefore does not mechanically grow because a bout is longer or contains more total licks.

Integrated interpretation
reference + action

Sustained population DA is best described as a multiplexed signal: substantial ongoing sampling/action information plus a learned reward-reference component that current action does not absorb.

Causal-order rule: 0–2 s licking is the preferred nuisance control for a 2–5 s neural endpoint. Concurrent 2–5 s licking is a stricter sensitivity analysis. Final bout duration and total lick count are deliberately treated as over-control because they include behavior occurring after the neural window begins and may partly sit downstream of dopamine-dependent persistence.
Partial variance
.049 vs .108

With flexible early+concurrent action terms, reference contributes unique ΔR²=.04895 and action contributes unique ΔR²=.10791; their shared component is only ≈.00214. Action is substantial, but it is not the same information as reference.

Conditional permutation
P = .0449

Reference remains after 0–2 s + 2–5 s action control: unique ΔR²=.04895, conditional P=.0449. Even whole-bout lick-count/rate/duration over-control leaves ΔR²=.03299, P=.0357.

Joint model
all three contribute

RWstate β=2.283 (P=.00171), 0–2 s licks β=.376 (P=.0165), and 2–5 s licks β=.554 (P=.000457). The data directly reject both “only value” and “only licking.”

Relative-value signature after action control

Current reward stays positive; learned reference stays negative

With early + concurrent action main effects controlled, current reward remains positive (U=+.815, P=8.6×10⁻⁵) and learned reference remains negative (R=−2.211, P=.00153). The corresponding U−R contrast is strongly positive (β=1.513, P=5.9×10⁻⁵).

If reward×action interactions are made extremely flexible, U becomes unstable because reward strongly drives action; critically, R remains negative (−2.054, P=.00253). That is the more diagnostic history term.

Temporal decomposition

Sampling/action comes first; reference appears later

In 0.5-s bins, prior within-bout sampling becomes FDR-significant from approximately 1–1.5 s onward. The reference coefficient turns positive around 3 s and is nominally significant through 4.5 s. Across ten exploratory bins those late reference tests reach BH q≈.076, so this is mechanistic timing evidence—not a separate corrected discovery.

Exact early-action matching
9 / 11

Matching high- versus low-reference bouts within animal and reward on identical 0–2 s lick count leaves 55 pairs; 9/11 animal effects are positive and the one-sided exact Wilcoxon P=.0415.

Nonlinear sensitivity
3 / 3 learners

Random Forest, ExtraTrees and HistGradientBoosting all leave a positive residual reference slope after nonlinear action removal; conditional permutation P=.0100, .0172 and .00170, respectively. Their held-animal DA nuisance prediction is weak, so this is a functional-form robustness test—not a prediction benchmark.

Prediction boundary
OOF R² ≈ .05

On this strict 192-bout subset, held-animal prediction gains are not stable. These analyses answer a mechanistic confound question; they should not be presented as a cross-animal prediction headline.

Biological interpretation

The combined result favors a sequential computation: sampled consumption first recruits a strong action/sensory component, then sustained dopamine increasingly carries the value of the current reward relative to a stored reference.

This should not be described as if bulk GRAB-DA in a 2–5 s window were identical to the canonical subsecond cue-locked TD prediction error. The safer terms are consummatory reference-dependent utility and sampled-reference relative value.

Biological implication: absence of behavioral contrast does not imply absence of reward memory. A reward reference may persist and be read out neurally while downstream comparison or action circuits fail to convert it into measurable behavior.

Shared neural–behavioral timescale

α=.20 was selected using held-animal dopamine prediction alone, then frozen before independent behavioral tests. The DA-defined state predicts log-duration behavior (β=.476, P=.00566) and termination hazard (β=−.780, OR=.459, P=.000180).

But this is not mediation proof

The safest conclusion is a shared reference axis used by both neural and behavioral outputs. The stimulation dissociation shows that neural reference expression alone is not sufficient for gross feeding behavior. Causal mediation remains an experimental question.

Interpretation boundary
Geometry ≠ same dynamics

Quinine and stimulation align with a comparison-like value direction, but their temporal trajectories are not uniquely better fit by U−R than by generic ramp/step alternatives. Cross-context generality therefore belongs to value geometry; the specific temporal U−R computation is identified in the matched-history experiment.

Why this distinction matters: history/reference, sensory quality, hunger, illness and dopamine stimulation can all move value, but they enter the architecture at different layers. The current biological model uses these manipulations to separate current utility, reference formation and readout/expression rather than forcing every manipulation into one latent variable.
Complete result series

From the model-free phenomenon to a mechanistic reward-reference architecture

The project did not begin with a chosen latent-state model. It progressed through seven increasingly restrictive questions: whether identical rewards differ after different histories; what updates the history state; whether that state is continuous and deeper than local adaptation; whether strong alternative models absorb it; when the comparison appears in dopamine; whether the computation generalizes; and whether dopamine contributes to persistence.

How to read this section: Figures 1–7 are the current science-rebuild progression. The later sections of this page add the newer 2026-10-03/04 persistence–expression and biological-model analyses on top of this established series; they do not replace it.
01

Identical current rewards acquire different value after different histories

The starting result is deliberately model free. The same current 100E or 20E reward is compared after different recent histories. Feeding persistence and 2–5 s sustained VTA dopamine both show the aligned reference effect in 9/9 animals (exact Wilcoxon P=.003906 for each).

The effect is also positive in all nine animals across 2–4, 2–5, 2.5–5 and 3–5 s windows, so the phenomenon is not created by one hand-picked late interval.

02

Sampled consumption, not passive waiting, updates the reference

A passive-time explanation predicts the internal state should move after a programmed switch even before the animal samples the new reward. It does not: across candidate passive time constants from 5 to 640 s, the maximal added sustained-DA R² before first sample is only about .004.

Once consumption begins, sampled exposure carries graded information. In the updated action adjudication, the reference remains unique after flexible 0–2 s action control (ΔR²=.0543, conditional P=.0464), after 0–2 + 2–5 s action control (ΔR²=.04895, P=.0449), and even after conservative whole-bout action over-control (ΔR²=.03299, P=.0357).

03

A continuous state generalizes across animals and retains deeper reward path

The continuous reference is useful because it is more informative than either current reward or categorical context. Held-out-animal sustained-DA R² increases from .038 for current reward alone to .123 with context and .175 with the continuous history state; context + state reaches .178.

Within fixed context, residual dopamine rises monotonically across history-state quartiles. After current reward, bout stage, block time, session progression, previous-block history and current-block consumption are controlled, deeper cumulative history still adds ΔR²=.02686 (conditional P=.00670).

The recency profile is broad, with a Natural-task optimum around α≈.15–.16. The point is an effective memory scale, not a claim that the brain contains an exact synaptic α.

04

Strong alternative models capture adaptation, but do not absorb cumulative path

The model room deliberately includes strong competitors rather than weak straw baselines: belief/HMM state inference, average reward rate, Pearce–Hall/uncertainty, adaptive gain, distributional analogues and recurrent Value-RNNs. Several predict held-out dopamine reasonably well; prediction ranking alone therefore does not identify the biological computation.

The decisive analysis is bidirectional unique information. FullHistory remains unique beyond belief (ΔR²=.0254, P=.0124), continuous HMM (.0266, P=.0090), average reward rate (.0256, P=.0122), Value-RNN (.0269, P=.0128), and Value-RNN + elapsed time (.0269, P=.0078). Reverse increments are small and generally not detected.

A nominal low-capacity H=2 RNN exception did not survive family-wise max-stat correction or a dedicated 12-seed confirmation. Distributional spread likewise adds essentially no population-photometry information beyond the central history state (P=.941).

05

Current reward becomes relative to stored history over the first seconds of consumption

In the same 192 post-switch bouts from 11 animals, the U−R coefficient is negative before feeding (β=−.485), weak during 0–2 s (β=+.294), and strongly positive during 2–5 s (β=+1.752). The sustained-minus-early increase is +1.458 with P=9.02×10⁻⁸, and 11/11 animals have a larger sustained than early slope (exact P=.000977).

This is not a pre-baseline subtraction artifact: on raw non-pre-subtracted z-signal, early U−R remains absent (β=−.191, P=.718) while 2–5 s U−R is already positive (β=+1.267, P=.0399). U+R does not show the corresponding temporal growth.

06

The history computation sits inside a broader value space

The Natural-task α=.20 state was frozen and transferred to an independent quinine/reward-quality task. In 66 strict pure-100E bouts from seven animals, the frozen state adds ΔR²=.02540 to whole-bout DA AUC (clustered P=.00141; within-animal circular-shift P=.00205); 6/7 animal slopes are positive.

Orthogonal manipulations also align with a value direction defined only by Natural 100E-versus-20E dopamine: quinine moves downward; VTA stimulation moves upward; hunger and LiCl occupy the same broader geometry but with weaker/less uniform sustained-DA effects. This establishes general value geometry without claiming every context reproduces the same temporal history computation.

07

Consumption-period dopamine contributes to feeding persistence

A history-state scale chosen from held-animal dopamine alone transfers to behavior: termination OR=.459, P=.000180. Causal manipulation converges on the same persistence axis. Dopamine activation during consumption reduces termination hazard (OR=.690, 95% CI .615–.775, P=3.29×10⁻¹⁰); contingent JAWS inhibition increases hazard (OR=1.341, 95% CI 1.031–1.746, P=.0289).

Noncontingent inhibition is weaker and not conventionally significant (OR=1.116, P=.0976); the contingent-versus-noncontingent interaction is borderline (P=.0515). The appropriate conclusion is that dopamine contributes to persistence, not that the entire history→DA→behavior chain has been proven as complete mediation.

Robustness & sensitivity

Earlier analyses that constrain what the main result is — and is not

These controls are not separate stories. They define the boundaries of the reward-reference claim: how deep the memory is, whether temporal emergence is an analysis artifact, whether a more nonlinear comparator is required, whether recurrent models discover a missing latent dimension, and which generalizations remain provisional.

Memory depth
P = .00620

No single prev1–prev4 block lag provides a clean independent cutoff. Yet after multiple lag summaries, total prior consumption and global-history summaries are all entered, the continuous recency-weighted state remains significant. The memory therefore looks like a smooth compressed trajectory rather than “exactly the previous N blocks.”

Raw-signal control
β = +1.267

On non-pre-subtracted raw z-signal, early 0–2 s U−R is absent (β=−.191, P=.718) while sustained 2–5 s U−R is already positive (β=+1.267, P=.0399). Temporal emergence is therefore not manufactured by subtracting a negative pre-bout baseline.

Normalization family
11 / 11 folds

Nested held-animal divisive-normalization fits drive normalization strength to the weakest tested boundary in all 11 folds and do not improve prediction over the near-linear U−R comparator. Reference-dependent nonlinear gain terms likewise add no reliable benefit.

Recurrent-state sensitivity
H=2 exception resolves

The nominal reward-only H=2 RNN increment (ΔR²≈.0153, nominal P≈.0226) does not survive 12-model max-stat correction (family-wise P≈.0646) and disappears in a dedicated 12-seed H=2 confirmation (RNN|FullHistory ΔR²≈.00443, P≈.186). FullHistory remains significant beyond the confirmed RNN.

RNN capacity confirmation
ΔR² ≈ .0269

At H=50 with 12-seed ensembles, reward-only and reward+time RNNs do not stably improve held-animal DA prediction (relative MAE ≈1.011 and 1.013). FullHistory still adds ≈.0269 unique R² (P≈.0128 and .0078), whereas the RNN contributes only ~4–5×10⁻⁵ beyond FullHistory (P≈.86).

Cohort boundary
P = .474

Leave-one-cohort-out FullHistory effects stay positive, but reduced subsets lose power and the animal-level exact cohort-label permutation is P=.474. The data therefore do not justify claiming perfect cohort invariance or a distinct VGLUT2-specific mechanism.

QE whole-bout robustness

The transfer is not created only by long bouts

Allowing FullHistory to interact with log(duration) gives interaction P=.382. At mean duration, the centered history effect remains positive (β≈65.91, clustered P=.0114). This excludes the simplest explanation that QE whole-bout AUC works only because very long bouts show a special history effect.

QE temporal expression

Shared computation, different waveform

In strict duration≥20 s pure-100E bouts, a positive history cluster is already present pre-bout, becomes weak around onset, and re-emerges strongly at approximately 8–12 s and 13–20 s. The cross-task result is therefore a shared history computation, not a claim of fixed latency or waveform.

Equivalent-state calibration
quinine ≈ −3 units

Descriptively mapping external manipulations onto the Natural FullHistory behavior scale gives quinine ≈−3.14 duration-state units and −2.67 hazard-state units. This is a calibration, not evidence that quinine literally edits the FullHistory latent state.

Equivalent-state calibration
stim ≈ +0.4–0.8

The 13-animal stimulation cohort maps to approximately +.49 duration-state / +.42 hazard-state units, while the independent 5-animal cohort maps to about +.81 / +.63. Two behavioral readouts agree in direction and scale.

Task boundary
Do not manufacture negatives

Stauffer marginal utility, Masset future-discount timescales and feature-specific RPE require reward-level, independent delay or feature manipulations that this design does not contain. They remain explicit design boundaries rather than being forced into artificial negative results.

Why keep these results visible: they show that the current model survived several places where an apparently strong story could have broken — window choice, baseline subtraction, local-history summaries, recurrent capacity, nonlinear normalization and cross-task duration structure — while also preserving honest boundaries where the present design is underidentified.
Classical reward contrast

Our VTA signal and classical cSNC should be connected, not collapsed into one mechanism

Successive negative contrast is classically defined by behavioral suppression after reward downshift. Lesion and circuit work suggests that storing a prior reward and expressing a behavioral comparison can be separable.

Gustatory thalamus

GT lesions abolish consummatory SNC even when the retention interval is extended from minutes to 24 h, arguing against a simple “prior reward was forgotten” account. GT lesions can also dissociate consummatory from instrumental SNC.

Insula and amygdala

Insular and BLA/CeA studies implicate reward-comparison and negative-affect circuitry. Recent c-Fos work further suggests that sufficiently large reward disparity recruits amygdala circuits associated with true cSNC.

VTA / NAc dopamine

Dopamine can carry relative incentive value, but our seconds-long consummatory signal is not identical to every classical reward-loss effect. Different output circuits may determine whether the neural comparison becomes behavior.

Reward contrast is not necessarily a unitary response to reward loss. It can be treated as the behavioral expression of a multi-stage computation: reward experience establishes a reference, current utility is evaluated relative to it, and context-specific circuits determine whether the comparison appears in dopamine, behavior, or both.
Falsifiable next steps

Experiments that separate the layers

The strongest next experiments are not more model variants on the same data. They orthogonalize variables that the present designs partially confound.

Priority 0

Homeostatic state × interleaved reward identity

Interleave two reward qualities in hungry vs sated animals and PBS vs semaglutide. Estimate separately: current utility shift, α, stored R, comparator gain, and DA-to-behavior coupling.

Decisive question: does physiological state alter U only, or also change reference formation/readout?

Priority 0

Delay × number of reward samples

Factorially vary elapsed time and the number/value of intervening reward samples. A sample-updated reference predicts sample count/value should dominate passive delay after matching.

Priority 0

Balanced upshift vs downshift

Match positive and negative mismatch magnitude, current reward statistics, and reward variance. This is required to identify g+ and g− without current-condition confounding.

Priority 0

DA mediation vs parallel readout

Match bouts for pre-existing R and perturb sustained VTA DA during consumption. If behavior changes while R is fixed, DA has a mediating/gating role; if not, reference can drive parallel output circuits.

Priority 1

VTA + BLA / insula / gustatory thalamus

Record VTA relative-value while perturbing classical reward-loss circuits in a matched downshift/upshift task. Test whether negative behavioral contrast depends on comparison circuits beyond VTA reference coding.

Priority 1–2

Variance, ambiguity, long memory and single cells

Manipulate reward variance to test adaptive gain; cue ambiguity to test belief-state inference; long delays/cross-day carryover to test slow references; and cellular-resolution VTA recordings to test distributional coding.
